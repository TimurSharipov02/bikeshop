# Шаблон технологической карты

Статус: черновик v0.1 · Дата: 2026-09-09

Технологическая карта — это инструкция на одну операцию из справочника видов
работ (`work-taxonomy.md`). По ней новый мастер выполняет работу без надзора, а
старший механик принимает результат по чётким критериям.

Одна карта = одна операция = один код (например, `DRV-01`).

---

## Структура карты

### Шапка

| Поле | Пояснение |
|---|---|
| Код операции | Из справочника видов работ, напр. `DRV-01` |
| Название | Внутреннее + для клиента |
| Версия карты | `1.0`, растёт при изменениях |
| Дата / автор / утвердил | Кто написал и кто утвердил как стандарт |
| Область применения | Типы велосипедов, ограничения (напр. «только механические группы») |
| Квалификация | L1 / L2 / L3 |
| Норма времени | Эталон в минутах + кем и на скольких велосипедах откалибрована |
| Рабочее место | Личный пост / общий пост |

### Инструмент

Список с пометками:
- **обяз.** — без него работу не начинать;
- **жел.** — ускоряет, но можно обойтись;
- **момент** — динамометрический, требует соблюдения момента затяжки;
- **поверка** — требует периодической поверки/калибровки (указать интервал).

### Расходники и материалы

Смазки, обезжириватель, ветошь, стяжки, герметик, фиксатор резьбы, тормозная
жидкость и т. д. — с нормой расхода, если она значима.

### Типовые запчасти

Что обычно меняется в рамках операции (трос, рубашка, колодки, оливка, наконечник).

### Входной контроль (до начала работы)

Чек-лист: что проверить и зафиксировать до того, как что-то крутить.
Например: износ смежных узлов, наличие скрытых повреждений, комплектность.
Если найдено то, что выходит за рамки операции → согласование доп. работ с клиентом.

### Порядок выполнения

Пронумерованные шаги. Для критичных соединений — **момент затяжки** прямо в шаге.
Каждый шаг — одно законченное действие, проверяемое глазами.

### Контроль качества (критерии приёмки)

Чек-лист, по которому старший механик или сам мастер принимает работу.
Формулировки измеримые: не «переключается хорошо», а «чёткое переключение по всем
передачам под нагрузкой на стенде, без задержек и перескоков».

### Проверка на стенде / тест-райд

Что и как проверяется в движении или на стенде.

### Типовые ошибки и подводные камни

Реальные грабли: что чаще всего делают не так и к чему это приводит.

### Требования безопасности

СИЗ, работа с жидкостями (DOT — едкая), давление (посадка tubeless), утилизация.

### Что зафиксировать в заказ-наряде

- фактическое время (таймер);
- заменённые запчасти и расходники;
- отклонения от карты и их причина;
- фото до/после для узлов, где это важно;
- моменты затяжки для ответственных соединений (для паспорта велосипеда).

## Пример заполнения: DRV-01 «Настройка заднего переключателя (механика)»

### Шапка

| Поле | Значение |
|---|---|
| Код | DRV-01 |
| Название | Внутр.: «Настройка заднего переключателя, механика» · Клиент: «Настройка заднего переключателя» |
| Версия | 1.0 |
| Дата / автор / утвердил | 2026-09-09 / старший механик / — (черновик) |
| Область применения | Механические группы 1x и 2x, шоссе / гревел / МТБ. Не для электронных групп (см. DRV-08). |
| Квалификация | L1 |
| Норма времени | 20 мин (черновик, не откалибровано) |
| Рабочее место | Личный пост, стойка + стенд для прокрутки |

### Инструмент

- Шестигранники 2–6 мм — **обяз.**
- Отвёртка крестовая PH1 — **обяз.** (винты H/L/B)
- Кусачки для тросов и рубашек — **обяз.**
- Инструмент для юстировки петуха — **жел.** (если есть подозрение на кривой петух → DRV-07)
- Стойка ремонтная — **обяз.**
- Динамометрический ключ 1–10 Н·м — **обяз.**, **момент**, **поверка** (раз в год)

### Расходники и материалы

- Наконечник троса — 1 шт.
- Концевик рубашки — по необходимости
- Смазка для троса / тефлоновый спрей — капля
- Обезжириватель, ветошь

### Типовые запчасти

- Трос переключения (если старый с заломами/коррозией) — DRV-06
- Рубашка с концевиками (если пережата/треснула) — DRV-06

### Входной контроль

1. Замерить износ цепи (DRV-09). Если цепь «тянется» ≥ 0.75% — предупредить: на
   изношенной трансмиссии идеальной настройки не будет, предложить замену.
2. Проверить петух на глаз и рукой: явное искривление → согласовать DRV-07.
3. Проверить состояние троса и рубашки: заломы, коррозия, пропилы → согласовать DRV-06.
4. Проверить ролики натяжителя на люфт и износ.
5. Проверить крепление переключателя к петуху (момент по спецификации, обычно 8–10 Н·м).

### Порядок выполнения

1. Установить велосипед в стойку, снять заднее колесо не требуется.
2. Перекинуть цепь на меньшую звезду (наружу), выключить натяжение троса:
   ослабить болт крепления троса.
3. Винтом **H** (High) выставить положение ролика напротив самой малой звезды:
   ролик в одной плоскости со звездой, цепь не трётся о рамку.
4. Винтом **L** (Low) — рукой аккуратно переведя переключатель к большой звезде —
   выставить крайнее положение так, чтобы ролик был напротив большой звезды и
   переключатель не уходил в спицы.
5. Винт **B** (Body/зазор): выставить зазор между верхним роликом и самой большой
   звездой ~5–6 мм (по спецификации группы) на большой звезде.
6. Прокрутить регулятор натяжения троса (барабанчик) в исходное — закрутить до
   упора и отпустить на 1 оборот.
7. Натянуть трос рукой, зафиксировать болтом с моментом по спецификации
   (обычно 5–7 Н·м, **момент**).
8. Вращая педали, переключиться на 2-ю звезду. Барабанчиком добиться чёткого
   и быстрого переключения вверх; проверить весь диапазон в обе стороны.
9. Подстроить под нагрузкой на стенде: если вверх идёт с задержкой — добавить
   натяжение (барабанчик против часовой), если перескакивает / шумит на меньших —
   убавить.
10. Обрезать трос, оставив 3–4 см, установить наконечник, закрепить у пера.
11. Протереть, смахнуть стружку, проверить, что ничего не трётся.

### Контроль качества

- [ ] Чёткое переключение по всем передачам вверх и вниз на стенде под нагрузкой,
      без задержек и двойных перескоков.
- [ ] На крайней малой звезде цепь не трётся о внешнюю рамку переключателя.
- [ ] На крайней большой звезде переключатель не касается спиц, ход остаётся запас.
- [ ] Зазор B-винта в пределах спецификации на большой звезде.
- [ ] Трос закреплён с нужным моментом, наконечник установлен, длина аккуратная.
- [ ] Барабанчик регулятора не в крайнем положении (есть запас в обе стороны).
- [ ] Нет посторонних шумов на средних передачах при прямой цепи.

### Проверка на стенде / тест-райд

Прокрутка на стенде во всём диапазоне под средней нагрузкой, 2 полных прохода
вверх и вниз. Для велосипедов спортсменов — короткий тест-райд с переключением
под усилием.

### Типовые ошибки и подводные камни

- Настройка H/L «по щелчку», а не по положению ролика относительно звезды.
- Слишком большое натяжение троса «чтобы вверх летело» → шум и перескок на малых.
- Игнор изношенной цепи/кассеты — настройка «плавает» через день.
- Кривой петух не проверен → идеально настроить невозможно, время потрачено.
- B-винт выставлен на малой звезде, а не на большой.
- Забыли момент на болте троса → трос проскальзывает, передачи «уезжают».

### Требования безопасности

Беречь пальцы у звёзд при прокрутке. Стружку троса убирать сразу — острая.

### Что зафиксировать в заказ-наряде

- Фактическое время.
- Заменённые расходники (наконечник, концевик).
- Износ цепи на входе (%).
- Если петух правился (DRV-07) или менялся трос (DRV-06) — отдельными операциями.
- Момент затяжки болта троса и болта переключателя — в паспорт велосипеда.
