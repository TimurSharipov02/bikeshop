# Электронные компоненты (EL)

Функции группы EL. Нотация — в `README.md`.

> Здесь только электронные группы переключения. Расписаны **Shimano Di2** и
> **SRAM AXS / eTap**. Другие системы (FSA K-Force WE, Campagnolo EPS) — вести
> строго по мануалу производителя:
> - Shimano — https://si.shimano.com
> - SRAM — https://www.sram.com/en/service
> - Campagnolo — https://www.campagnolo.com (Technical Documents)
> - FSA WE — https://www.fsawe.net
>
> Приводы e-bike (мотор, батарея, дисплей) — не здесь, обслуживаем по спросу.

### ФУНКЦИЯ Обновить прошивку компонентов(система: Di2 | AXS)

```
Код операции : EL-01
Вход         : велосипед на стойке; АКБ заряжена ≥ 50 %; стабильный интернет
Инструмент   : смартфон / ПК с приложением (Shimano E-Tube Project; SRAM AXS),
               кабель подключения (Di2 проводной — интерфейс SM-PCE; иначе Bluetooth)
```

```
1. ВХОДНОЙ КОНТРОЛЬ: система и компоненты; заряд ≥ 50 % (обновление на низком
   заряде может вывести компонент из строя).

2. ЕСЛИ Shimano Di2:
   2.1. Подключить: проводные — через интерфейс к порту зарядки / блоку;
        полу-беспроводные (12 ск) — по Bluetooth к манеткам / переключателю.
   2.2. В E-Tube Project → «Обновление»; приложение покажет версии по каждому
        компоненту.
   2.3. Обновлять по очереди, не отключая питание; дождаться подтверждения по
        каждому.
   2.4. После — проверить назначение кнопок и режим переключения (могли сброситься).

3. ЕСЛИ SRAM AXS:
   3.1. В приложении AXS добавить устройства (по одному «разбудить» кнопкой),
        приложение покажет доступные прошивки.
   3.2. Обновлять по одному компоненту; кнопки не трогать, батарею не снимать.
   3.3. После — проверить, что сопряжение сохранилось (иначе → ВЫЗОВ Настройка
        кнопок и сопряжение() [EL-03]).
```

```
ПРОВЕРКА КАЧЕСТВА:
  - все компоненты на актуальной версии; переключение работает;
  - кнопки и режимы как назначены.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - версии до и после по каждому компоненту.
```

ИСТОЧНИКИ:
- Shimano dealer manuals — https://si.shimano.com
- SRAM service — https://www.sram.com/en/service

### ФУНКЦИЯ Диагностика электронной группы()

```
Код операции : EL-02
Вход         : велосипед на стойке
Инструмент   : смартфон с приложением, инструмент для разъёмов e-tube, зарядное
               устройство, запасные CR2032
```

```
1. ЗАРЯД:
   1.1. Shimano Di2 → удержать любую кнопку манетки до индикатора:
          зелёный 2 сек = полный; 5 миганий зелёным ≈ 50 %; красный 2 сек ≈ 25 %;
          5 миганий красным ≈ 0 %.
   1.2. SRAM AXS → нажать кнопку AXS на компоненте:
          зелёный = > 25 %; красный = 15–25 %; мигает красным = < 15 %;
          нет реакции = разряжен. Батарейки манеток (CR2032) — отдельно.

2. ПИТАНИЕ И ПРОВОДКА (Di2 проводной):
   2.1. Осмотреть провода EW-SD на переломы; разъёмы — на окисление и неполную
        посадку.
   2.2. Разъёмы отсоединять ТОЛЬКО инструментом, поддевая корпус; НЕ тянуть за провод.
   2.3. Прощёлкать каждый разъём заново; проверить блоки соединений (Junction).

3. СИМПТОМЫ:
   3.1. Не переключает совсем, нет индикации → разряд / обрыв питания / дохлый узел.
   3.2. Переключает через раз, «уезжает» → разряд / плохой разъём / нужна
        микронастройка (DRV-08).
   3.3. Di2 «safe mode» (после удара цепи в спицы) → долгое нажатие кнопки режима,
        звуковой сигнал = сброс.
   3.4. AXS: не отвечает одна манетка → заменить CR2032, пере-сопрячь [EL-03].

4. ПРИЛОЖЕНИЕ: подключиться, посмотреть статус компонентов, коды ошибок, счётчики.

5. ВЫВОД: что зарядить / заменить / пере-сопрячь; неисправный компонент — замена.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - заряд по всем узлам известен; разъёмы чистые и посажены;
  - выдан понятный вердикт.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - заряд по узлам; проблемы разъёмов / проводов; коды ошибок; вердикт.
```

ИСТОЧНИКИ:
- Park Tool, Di2 Shimano Electronic System Installation — https://www.parktool.com/en-us/blog/repair-help/di2-shimano-electronic-intelligent-system-installation
- Shimano SI — https://si.shimano.com ; SRAM service — https://www.sram.com/en/service

### ФУНКЦИЯ Настройка кнопок и сопряжение()

```
Код операции : EL-03
Вход         : велосипед на стойке; АКБ заряжена
Инструмент   : смартфон с приложением
```

```
1. СОПРЯЖЕНИЕ (после замены компонента или потери связи):
   1.1. SRAM AXS:
          - задний переключатель: кнопку AXS удержать до мигания зелёным, отпустить;
          - передний переключатель: так же;
          - каждая манетка: удержать кнопку AXS до ЧАСТОГО мигания зелёным, отпустить;
          - завершить коротким нажатием кнопки на заднем переключателе — мигание
            прекращается.
   1.2. Shimano Di2: проводные — связь авто по подключению; беспроводные —
        «подключить устройство» в E-Tube Project.

2. НАЗНАЧЕНИЕ КНОПОК:
   2.1. В приложении задать функцию каждой кнопки / паддла (переключение вверх /
        вниз, перекидка спереди, страницы велокомпьютера, свет).
   2.2. Shimano: режим — ручной / полу-синхро / синхро; задать точки авто-перекидки
        переднего.

3. РАСШИРЕНИЯ (blips / satellite / hood / bar-end):
   3.1. Подключить физически (Di2 — в порт манетки / блока; AXS blips — в разъём
        манетки или беспроводные).
   3.2. Назначить функции в приложении.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - каждая кнопка и расширение делают назначенное;
  - синхро-точки логичны и не «дёргают» передний на ходу.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - карта назначений; режим; добавленные расширения.
```

ИСТОЧНИКИ:
- Park Tool, SRAM AXS Shifter Pairing — https://www.parktool.com/en-us/blog/repair-help/sram-axs-shifter-pairing
- Shimano SI — https://si.shimano.com

### ФУНКЦИЯ Установить датчик мощности()

```
Код операции : EL-04
Вход         : велосипед на стойке
Инструмент   : по типу датчика (hex / Torx, инструмент снятия шатунов — см. bb.md,
               педальный ключ, инструмент звёзд), приложение датчика / велокомпьютер
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Тип датчика: в шатуне / в спайдере / в оси каретки / в педалях / во втулке.
   1.2. Совместимость с системой и рамой (ЗАЗОР до пера!); протокол (ANT+ / BLE);
        питание (батарейка / аккумулятор / зарядка).

2. МОНТАЖ:
   2.1. Шатун / спайдер → ВЫЗОВ вспомогательной функции снятия/установки шатунов
        (bb.md) и/или Заменить систему или звёзды() [DRV-05]; моменты по
        спецификации датчика.
   2.2. Педали → ВЫЗОВ Заменить или обслужить педали() [BB-05]; следить за L / R
        и моментом.
   2.3. Проверить зазор датчика до пера рамы и до цепи на всех передачах.

3. ПАРА И НАСТРОЙКА:
   3.1. Установить / зарядить питание; разбудить датчик (прокрутить шатуны).
   3.2. Спарить с велокомпьютером / приложением по ID.
   3.3. Задать длину шатуна.

4. КАЛИБРОВКА:
   4.1. Обнуление (zero offset): без нагрузки на педали, шатуны горизонтально,
        команда «калибровка» в компьютере.
   4.2. При наличии — статическая калибровка с известным весом на педали по
        инструкции датчика.

5. ПРОВЕРКА: датчик даёт мощность на тест-прокрутке под нагрузкой; L / R баланс
   адекватен (для двусторонних); зазоры в норме.
```

```
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель датчика; длина шатуна; выполнено обнуление / калибровка.
```

ИСТОЧНИК: мануал датчика мощности; Park Tool, Di2 Shimano Electronic System
Installation (смежное) — https://www.parktool.com/en-us/blog/repair-help/di2-shimano-electronic-intelligent-system-installation
