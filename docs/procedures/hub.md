### ФУНКЦИЯ Обслужить втулку на промподшипниках()

```
Код операции : HUB-01
Вход         : колесо снято
Инструмент   : набор съёмников глухих подшипников (blind bearing puller),
               набор оправок / пресс для запрессовки, мягкая киянка, шестигранники
               и Torx, штангенциркуль, тиски с губками для оси
Расходники   : промподшипники нужных типоразмеров, лёгкая смазка / антисиз на
               посадочные места
```

```
ОБЩИЕ ПРИНЦИПЫ:
  - Промподшипник (industrial / cartridge) НЕ регулируется и НЕ разбирается —
    изношенный меняется целиком.
  - Типоразмер выбит на обойме (напр. 6902 = 15×28×7 мм, 6802, 688, 6001).
    Если стёрт — замерить внутренний диаметр × наружный × ширину.
  - Запрессовывать и выпрессовывать ТОЛЬКО за ту обойму, которая с натягом
    (в корпусе — за наружную; на оси — за внутреннюю). Через шарики усилие
    не передавать.
  - Преднатяг у большинства втулок задаётся регулируемой крышкой / кольцом /
    подбором проставок — по системе бренда.

1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Снять кассету [DRV-04] / ротор [BRK-07] при необходимости.
   1.2. Признаки: люфт обода вбок; хруст / ступенчатый ход при вращении оси
        пальцами; тугой ход после мойки под давлением.
   1.3. Посчитать и замерить подшипники: обычно 2 в корпусе втулки + 1–2 в
        барабане (барабан — HUB-03).

2. РАЗБОРКА:
   2.1. Снять наконечники / крышки оси. По бренду они: стягиваются руками,
        откручиваются шестигранниками «на встречу» друг другу, или на резьбе.
   2.2. Вынуть ось. ЕСЛИ барабан сидит на этой же оси → снять барабан (HUB-03,
        шаг 2).
   2.3. Выпрессовать старые подшипники из корпуса: съёмником глухих подшипников
        изнутри, либо оправкой через противоположный подшипник, ударяя равномерно
        крест-накрест. Так же из барабана.

3. ОСМОТР:
   3.1. Посадочные места в корпусе — на разбитость, овал, задиры.
        ЕСЛИ посадка разбита (подшипник «болтается») → СОГЛАСОВАТЬ замену втулки.
   3.2. Ось прокатить по плоскости — погнута → замена.
   3.3. Собачки / храповик барабана (если разбирается) — осмотр, при износе → HUB-03/04.

4. СБОРКА:
   4.1. Тонкий слой смазки / антисиза на посадочные места (не «намертво»).
   4.2. Запрессовать новые подшипники строго соосно оправкой нужного диаметра
        по правильной обойме, до полной посадки в упор.
   4.3. Собрать ось, барабан, наконечники.
   4.4. Выставить преднатяг по системе бренда: затянуть регулировочную крышку /
        кольцо до исчезновения осевого люфта БЕЗ закусывания вращения;
        законтрить (стопорный винт / контргайка), если предусмотрено.

5. ПОСТАВИТЬ кассету / ротор.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - ось вращается свободно и ровно, без «песка»;
  - в собранном колесе с зажатой осью бокового люфта на ободе нет;
  - после установки кассеты / ротора переключение чистое.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - типоразмеры и число заменённых подшипников; бренд втулки;
  - способ выставления преднатяга; состояние посадочных мест.
```

ИСТОЧНИК: общая практика замены промподшипников; детали разборки и преднатяга —
мануал бренда втулки (DT Swiss, Industry Nine, Hope, Chris King и т.п.).
Смежное — Park Tool, Freehub Service — https://www.parktool.com/en-us/blog/repair-help/freehub-service

### ФУНКЦИЯ Обслужить втулку на насыпных конусах()

```
Код операции : HUB-02
Вход         : колесо снято
Инструмент   : конусные ключи нужных размеров, тиски с губками для оси,
               рожковые ключи, магнитный карандаш, густая смазка, растворитель, ветошь
Расходники   : шарики (комплект), при износе — конусы, ось
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Снять эксцентрик, кассету / фривил.
   1.2. Признаки: люфт обода; «песок» / ступеньки при медленном вращении оси
        пальцами.
   1.3. Посчитать витки резьбы оси за контргайкой с каждой стороны — ориентир
        при сборке.

2. РАЗБОРКА (одна сторона, обычно левая):
   2.1. Зажать ось в тисках правой стороной вниз (или держать конус ключом).
   2.2. Конусным ключом держать конус, рожковым ослабить контргайку против
        часовой.
   2.3. Снять контргайку и шайбы по порядку (на проволоку / стяжку), выкрутить конус.
   2.4. Вынуть ось, поймать шарики, собрать магнитом. Посчитать: зад обычно
        9 шт 1/4″ на сторону, перед 10 шт 3/16″ на сторону.

3. ЧИСТКА И ОСМОТР:
   3.1. Промыть чашки, конусы, ось, шарики.
   3.2. Провести кончиком шариковой ручки по беговой дорожке чашек и конусов.
        Гладкая — норма. Кончик цепляется, «спотыкается», проваливается в ямки —
        дорожка выработана (мелкие вмятины и раковины от шариков).
        ЕСЛИ на дорожке конуса ямки, раковины или ступенька → заменить конус.
        ЕСЛИ та же выработка на чашке корпуса (чашка запрессована, не меняется) →
        СОГЛАСОВАТЬ замену втулки / колеса.
   3.3. Шарики потускнели, с пятнами или огранкой → заменить все комплектом.
   3.4. Прокатить ось по ровной плоскости — если виляет, ось погнута, заменить.

4. СБОРКА:
   4.1. Смазать резьбу оси; заложить густую смазку в чашки корпуса.
   4.2. Уложить шарики в обе чашки, накрыть смазкой; шарики лежат ровно.
   4.3. Правую сторону собрать на исходный вылет оси, контргайку затянуть полностью.
   4.4. Вставить ось справа; левую сторону собрать без затяжки контргайки.

5. РЕГУЛИРОВКА:
   5.1. ЕСЛИ ось под эксцентрик → подвести конус до касания шариков, отпустить
        на 1/4 оборота (нарочно слишком свободно); держа конус ключом, затянуть
        контргайку полностью. Зажатый эксцентрик выберет этот люфт.
   5.2. ИНАЧЕ (сплошная ось) → малыми шагами (~1/32 оборота) затягивать конус до
        исчезновения люфта при свободном вращении; затянуть контргайку; перепроверить.
   5.3. Цель — самое свободное положение без стука и люфта.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - в собранном колесе с зажатым эксцентриком нет бокового люфта на ободе;
  - вращение ровное, без «песка».
ФИКСИРОВАТЬ В НАРЯДЕ:
  - замены (конусы, шарики, ось); число и размер шариков; состояние чашек.
```

### ФУНКЦИЯ Обслужить барабан (freehub)()

```
Код операции : HUB-03
Вход         : колесо снято
Инструмент   : hex 10 / 12 мм (болт барабана), кисти, растворитель, жидкое масло
               для барабана, густая смазка (для собачек), ветошь, динамометрический ключ
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Признаки: барабан не всегда цепляет (проскок педалей), тугой возврат,
        хруст, слабый или пропадающий треск.
   1.2. Снять кассету [DRV-04], ротор при необходимости.

2. СНЯТЬ БАРАБАН:
   2.1. Hex-ключом (Shimano — 10 мм; другие — 11 / 12 мм) выкрутить болт крепления
        барабана изнутри втулки со стороны кассеты (у некоторых — слева).
        Болт очень тугой.
   2.2. Стянуть барабан с оси; вместе с ним обычно снимается правая крышка оси.

3. ЧИСТКА:
   3.1. НЕ поддевать правый пыльник барабана Shimano — повредишь. Чистить вокруг
        него кистями и ветошью.
   3.2. Промыть тело барабана в растворителе, вращая; НЕ замачивать (загрязнит
        промподшипники внутри).

4. СМАЗКА:
   4.1. Внутрь барабана — ЖИДКОЕ масло (не густую смазку); закапать с обеих
        сторон, повращать для распределения.
   4.2. ЕСЛИ барабан разборный, с собачками и пружинами → тонкий слой густой
        смазки на собачки, пружины и зубья храповика.

5. СБОРКА:
   5.1. Надеть барабан на ось, наживить болт.
   5.2. Затянуть болт крепления моментом ≈ 40 Н·м.
   5.3. Собрать крышку оси, кассету, ротор.

6. ЕСЛИ проскок / хруст / заедание осталось → ВЫЗОВ Заменить барабан или
   стандарт оси() [HUB-04].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - зацепление сразу, ровный треск по кругу, свободный обратный ход;
  - осевого люфта нет.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - тип смазки; разбирался ли механизм собачек; момент болта барабана.
```

### ФУНКЦИЯ Заменить барабан или стандарт оси(что меняем: барабан | стандарт оси)

```
Код операции : HUB-04
Вход         : колесо снято
Инструмент   : hex, съёмник наконечников оси
Расходники   : барабан под модель втулки / конверсионный комплект оси и
               наконечников под нужный стандарт
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. ЕСЛИ меняем барабан → подобрать точно под модель втулки и тип посадки
        кассеты (HG / XD / XDR / Micro Spline).
   1.2. ЕСЛИ меняем стандарт оси → убедиться, что производитель втулки предлагает
        конверсионный комплект под нужный размер (QR 135, 12×142, Boost 12×148,
        15×100 / 110 и т.д.); уточнить длину оси.

2. ЕСЛИ меняем барабан:
   2.1. Снять кассету и ротор; снять старый барабан (HUB-03, шаг 2).
   2.2. Осмотреть промподшипники под барабаном; при износе → ВЫЗОВ Обслужить
        втулку на промподшипниках() [HUB-01].
   2.3. Поставить новый барабан, болт с моментом ≈ 40 Н·м.

3. ЕСЛИ меняем стандарт оси:
   3.1. Снять наконечники оси с обеих сторон.
   3.2. ЕСЛИ меняется сама ось (QR → сквозная) → вынуть старую, поставить новую
        нужной длины и диаметра.
   3.3. Установить новые наконечники / адаптеры под стандарт рамы или вилки.
   3.4. Выставить преднатяг подшипников по системе бренда.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - колесо встаёт в раму / вилку без осевого зазора и распора;
  - ось вращается ровно; барабан цепляет чётко;
  - после установки кассеты переключение чистое.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - новый барабан (тип посадки) / новый стандарт оси (размер);
  - заменены ли подшипники; момент болта барабана.
```
