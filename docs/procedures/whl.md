### ФУНКЦИЯ Шиномонтаж клинчер(объём: замена камеры | замена покрышки | покрышка и камера)

```
Код операции : WHL-01
Вход         : колесо снято или доступно
Инструмент   : пластиковые монтажки (НЕ отвёртка / металл), насос или компрессор
               с манометром, ветошь
Расходники   : камера / покрышка / ободная лента — по объёму
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Сверить размер покрышки и камеры (ETRTO), тип и длину вентиля
        (Presta / Schrader), диапазон давления на боковине.

2. СНЯТЬ:
   2.1. Снять колпачок и контргайку вентиля, полностью спустить (даже остаток
        воздуха мешает).
   2.2. Обмять оба борта к центру обода (в канал) по всей окружности.
   2.3. Поддеть один борт монтажкой, вести по кругу; при необходимости вторая
        монтажка. Ничего острого.
   2.4. Вынуть камеру; при замене покрышки снять и второй борт.

3. ЕСЛИ ремонт по проколу → ДИАГНОЗ:
   3.1. Накачать камеру, найти прокол (слух / вода).
   3.2. Сопоставить с местом на покрышке — найти причину внутри (осколок, порез,
        торчащая головка спицы, сбитая ободная лента).

4. ПОСТАВИТЬ:
   4.1. Один борт на обод, учитывая направление вращения (стрелка на боковине).
   4.2. Слегка подкачать камеру (держит форму), вставить вентиль прямо, заправить
        камеру внутрь без складок.
   4.3. Завести второй борт руками от вентиля в обе стороны; последний участок —
        большими пальцами; монтажка ОСТОРОЖНО, не прищемив камеру.
   4.4. Пройти по кругу с обеих сторон — камера не прикушена бортом.

5. НАКАЧАТЬ:
   5.1. До ≈ 1 бар — проверить посадку борта (линия-индикатор равномерна по кругу
        с обеих сторон); при перекосе спустить и поправить.
   5.2. До рабочего давления (по весу райдера и боковине), не выше макс.
   5.3. Контргайка вентиля от руки, колпачок.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - держит давление; борт сидит ровно по всему кругу;
  - покрышка не бьёт при вращении; камера нигде не прикушена.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - что менялось (камера / покрышка / лента), размер и модель;
  - давление на выходе; причина прокола, если найдена.
```

### ФУНКЦИЯ Установить бескамерку()

```
Код операции : WHL-02
Вход         : колесо снято
Инструмент   : монтажки, компрессор или бустер, съёмник золотника вентиля,
               шприц для герметика, спирт / ацетон, мыльная вода, ветошь
Расходники   : ободная лента нужной ширины, бескамерный вентиль, герметик
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Обод и покрышка совместимы с бескамеркой (tubeless-ready / UST).
   1.2. Ширина ленты — под внутренний канал обода; длина вентиля — под профиль.

2. ПОДГОТОВКА ОБОДА:
   2.1. Снять старую ленту, очистить канал спиртом / ацетоном (без масляной плёнки).
   2.2. Наклеить новую ленту с натягом по центру канала, нахлёст 5–10 см,
        продавить в канал и к стенкам, без пузырей и складок.
   2.3. Вскрыть отверстие под вентиль, вставить вентиль, гайку от руки + чуть
        ключом (перетяжка рвёт ленту).

3. МОНТАЖ ПОКРЫШКИ:
   3.1. Направление вращения по стрелке.
   3.2. Насадить оба борта; на трудном участке — мыльная вода на борт.

4. ПОСАДКА БОРТА:
   4.1. Выкрутить золотник вентиля.
   4.2. Подать большой объём воздуха — борта должны звонко «щёлкнуть» на полки.
   4.3. Проверить линию-индикатор по кругу с обеих сторон; при неровности
        спустить, мыльная вода, повторить.

5. ГЕРМЕТИК (один из способов):
   5.1. Через открытый борт: до накачки оставить участок борта у вентиля снятым,
        залить дозу по боковине, домонтировать, накачать.
   5.2. Через вентиль: борт уже сидит, золотник выкручен — шприцем внести дозу,
        вкрутить золотник, подкачать.

6. РАСПРЕДЕЛЕНИЕ:
   6.1. Накачать до макс. давления по боковине для посадки, затем сбросить до
        рабочего.
   6.2. Крутить и покачивать колесо, класть поочерёдно на бок.
   6.3. Дать выстояться, подкачивать каждые несколько часов; полная герметизация
        может занять до нескольких дней.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - держит рабочее давление ночь;
  - борт ровно по кругу с обеих сторон; вентиль не травит.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - ширина ленты, модель вентиля, объём герметика, давление на выходе.
```

### ФУНКЦИЯ Отремонтировать прокол бескамерки()

```
Код операции : WHL-03
Вход         : колесо на велосипеде или в руках
Инструмент   : инструмент установки жгутов, жгуты, нож / кусачки, насос
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Найти прокол (шипение, пузыри с мыльной водой, пятно герметика).
   1.2. Оценить:
          - боковина / крупный порез → жгут ненадёжен → замена покрышки, аварийно
            поставить камеру, СОГЛАСОВАТЬ С КЛИЕНТОМ;
          - протектор, прокол до ~3–4 мм → жгут.

2. Очистить зону, извлечь инородное тело.

3. ЖГУТ:
   3.1. Заправить жгут в иглу инструмента.
   3.2. Ввести в прокол под небольшим углом почти на всю глубину, оставив
        10–15 мм снаружи.
   3.3. Резко вынуть инструмент — жгут остаётся в проколе.
   3.4. Подкачать, крутнуть колесо — герметик дозакроет.
   3.5. Через минуту подрезать излишек заподлицо (или оставить — сотрётся).

4. ЕСЛИ после 1–2 жгутов не держит → камера аварийно / замена покрышки,
   СОГЛАСОВАТЬ.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - держит рабочее давление; на тест-прокрутке не травит.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - место и размер прокола; число жгутов; вердикт о ресурсе покрышки.
```

### ФУНКЦИЯ Обслужить бескамерку()

```
Код операции : WHL-04
Вход         : колесо снято или доступно
Инструмент   : съёмник золотника вентиля, шприц для герметика, ветошь, мыльная вода
Расходники   : герметик; при необходимости лента и вентиль
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Срок с последней заправки (обычно 2–6 мес — зависит от климата и герметика).
   1.2. Проверить, жив ли герметик (плеск при качании) или засох.

2. ЕСЛИ герметик засох комками:
   2.1. Снять покрышку (WHL-01, шаг 2), удалить сгустки и налёт со стенок и борта.
   2.2. Осмотреть ленту и вентиль, заменить при повреждении.
   2.3. Собрать заново по WHL-02, шаги 3–6.

3. ЕСЛИ герметик просто убыл:
   3.1. Спустить, повернуть вентиль к 6 часам, выкрутить золотник.
   3.2. Шприцем добавить дозу по боковине (с учётом остатка).
   3.3. Вкрутить золотник, накачать до рабочего, распределить прокруткой и
        покачиванием.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - держит давление; вентиль проходим, не забит.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - долив или полная переборка; объём герметика; замена ленты / вентиля.
```

### ФУНКЦИЯ Отправить колесо(дефект: восьмёрка | яйцо | зонт | комбинированный; тяжесть: лёгкая | сложная)

```
Код операции : WHL-05
Вход         : велосипед на стойке или колесо в станке
Инструмент   : станок для правки (или велосипед + стационарный индикатор),
               спицевой ключ нужного размера, держатель бладовых спиц, прибор
               для зонта, тензометр, лёгкая смазка
```

```
ЗАМЕТКА о направлении: смотреть от торца ниппеля СНАРУЖИ обода — по часовой
затягивает. На станке / велосипеде выглядит как против часовой.

1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Лёгкая правка — покрышку можно не снимать; сложная — снять.
   1.2. Проверить: сломанные / ослабшие спицы → ВЫЗОВ Замена спицы() [WHL-06];
        трещины у отверстий обода; износ тормозной поверхности (обод); люфт втулки.
   1.3. ЕСЛИ обод разбит / треснул → СОГЛАСОВАТЬ замену обода или колеса
        (правка бессмысленна).

2. БОКОВОЕ БИЕНИЕ (восьмёрка) — первым:
   2.1. Вращать, подвести индикатор к месту максимального ухода.
   2.2. Найти спицу в центре ухода; тянуть спицу с ПРОТИВОПОЛОЖНОГО фланца
        (в сторону от индикатора); при необходимости слегка ослабить соседнюю
        с ближнего фланца.
   2.3. Шаг: 1/4 оборота (крупный уход — до 1/2, мелкий — 1/8).
   2.4. Цель: ≤ 0.5 мм.

3. РАДИАЛЬНОЕ БИЕНИЕ (яйцо):
   3.1. Найти «высокие» (обод уходит от втулки) и «низкие» участки.
   3.2. Высокий участок → подтянуть ЧЁТНОЕ число спиц с ОБОИХ фланцев (по 1/2).
   3.3. Низкий участок → ослабить пару спиц с обоих фланцев.
   3.4. Каждые 3–4 радиальных правки проверять боковое.
   3.5. Цель: ≤ 1 мм.

4. ЗОНТ (центровка):
   4.1. Прибором замерить с обеих сторон.
   4.2. При смещении — подтянуть все спицы одной стороны (или ослабить другой)
        на равную величину (1/4–1/2), сохраняя боковое.

5. НАТЯЖЕНИЕ:
   5.1. Тензометром проверить равномерность по кругу и попадание в диапазон
        (по спецификации обода; ориентир — задняя приводная ~100–120 кгс).
   5.2. Снять напряжение: по кругу сжать пары спиц руками, перепроверить правку.

6. ФИНАЛ: капля смазки на резьбу ниппелей (при монтаже новых), протереть,
   поставить покрышку.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - восьмёрка ≤ 0.5 мм, яйцо ≤ 1 мм, зонт в норме;
  - натяжение равномерное и в диапазоне; спицы «отзвенели».
ФИКСИРОВАТЬ В НАРЯДЕ:
  - какие дефекты правились; замены спиц; итоговое натяжение (если мерили).
```

### ФУНКЦИЯ Заменить спицу()

```
Код операции : WHL-06
Вход         : велосипед на стойке или колесо в станке
Инструмент   : инструмент правки, спицевой ключ, тензометр, съёмник кассеты /
               ротора (при необходимости)
Расходники   : спица нужной длины и типа, ниппель, смазка на резьбу
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить сторону и зону облома (у фланца / у ниппеля / посередине).
   1.2. ЕСЛИ сломано более 1–2 спиц ИЛИ обломы у фланца по усталости →
        вероятен ресурс колеса; СОГЛАСОВАТЬ переспицовку / замену.
   1.3. Определить длину и тип: замерить целую спицу с той же стороны либо
        рассчитать → ВЫЗОВ Подбор длины спиц() [WHL-07]; J-bend или прямая тяга;
        круглая / бладовая.

2. ДОСТУП:
   2.1. Снять покрышку в зоне ремонта (или полностью).
   2.2. ЕСЛИ спица со стороны кассеты / ротора → ВЫЗОВ Заменить кассету() [DRV-04]
        / Заменить или отправить ротор() [BRK-07].
   2.3. Извлечь обломки спицы и ниппель.

3. УСТАНОВКА:
   3.1. Провести новую спицу тем же узором плетения, что у соседних на этом фланце
        (через / над — как остальные).
   3.2. Наживить ниппель, капля смазки на резьбу.
   3.3. Подтянуть до натяжения соседних спиц той же стороны.

4. ВЫЗОВ Отправить колесо() [WHL-05] — локально свести биения и натяжение.
5. Собрать кассету / ротор и покрышку.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - натяжение новой спицы = соседним; колесо в допуске; спицы отзвенели.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - число и позиции заменённых спиц; длина и тип; вердикт о ресурсе колеса.
```

### ФУНКЦИЯ Подобрать длину спиц()

```
Код операции : WHL-07
Инструмент   : рулетка / штангенциркуль, 2 спицы-эталона с ниппелями,
               калькулятор спиц / таблица
```

```
1. СОБРАТЬ ДАННЫЕ: число отверстий; модель втулки (PCD фланцев, отступы центра,
   диаметр отверстий фланца); модель обода.

2. ERD (эффективный диаметр обода):
   2.1. Вкрутить 2 ниппеля в 2 спицы-эталона до момента, когда конец спицы
        у дна шлица ниппеля.
   2.2. Вставить в противоположные отверстия обода, свести внахлёст, замерить
        между торцами спиц и прибавить поправку до дна шлица (обычно ×2) → ERD.

3. РАСЧЁТ: ввести ERD, параметры втулки, число крестов (обычно 3× для 32/36
   отверстий, 2× для лёгких / малоспицевых) в калькулятор → длины отдельно
   левая и правая.

4. ПРОВЕРКА ЗДРАВОГО СМЫСЛА:
   - слишком коротка → много резьбы видно у ниппеля (плохой зацеп);
   - слишком длинна → торчит за ниппель, трёт ленту → прокол.

5. Для ремонта одной спицы — замер целой спицы той же стороны как быстрый
   ориентир.
```

```
ФИКСИРОВАТЬ В НАРЯДЕ:
  - рассчитанные длины Л / П; число крестов; ERD; модель втулки и обода.
```

### ФУНКЦИЯ Собрать колесо()

```
Код операции : WHL-08
Инструмент   : станок для правки, прибор для зонта, тензометр, спицевые ключи,
               держатель бладовых спиц, отвёртка для ниппелей, смазка / фиксатор
               резьбы ниппелей
Расходники   : втулка, обод, спицы Л / П нужной длины, ниппели, ободная лента
```

```
1. ВХОДНОЙ КОНТРОЛЬ: комплектность; совпадение числа отверстий втулки и обода;
   выбран узор (число крестов). Длины спиц — из ВЫЗОВ Подобрать длину спиц() [WHL-07].

2. ШНУРОВКА:
   2.1. Первая группа: спицы в один фланец, вывести, зашнуровать в обод по узору,
        учитывая позицию клапанного отверстия (спицы не перекрывают доступ к
        вентилю).
   2.2. Вторая группа того же фланца, затем два встречных набора второго фланца —
        соблюдая направление тяги (ведущая / тянущая).
   2.3. Наживить все ниппели на 2–3 нитки.

3. РАВНОМЕРНАЯ ПРЕДНАТЯЖКА:
   3.1. По кругу подтягивать каждый ниппель на одинаковое число оборотов, пока
        не скроется видимая резьба.
   3.2. Малыми равными шагами по кругу довести до ~50 % целевого натяжения.

4. ВЫЗОВ Отправить колесо() [WHL-05] — циклами: зонт → боковое → радиальное,
   поднимая натяжение к рабочему.

5. СНЯТИЕ НАПРЯЖЕНИЯ: сжимать пары спиц по кругу, править, повторять, пока правка
   не перестанет «уезжать».

6. ФИНАЛ: тензометром выровнять натяжение (разброс в пределах ~20 %), проверить
   зонт и биения, подрезать выступающие спицы, поставить ленту.
```
