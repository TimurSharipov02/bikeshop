### ФУНКЦИЯ Настроить механические тормоза(тип: ободные | механический диск)

```
Код операции : BRK-01
Вход         : велосипед на стойке
Инструмент   : шестигранники / Torx, натяжитель троса, кусачки, динамометрический ключ
Расходники   : наконечник троса
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить тип тормоза.
   1.2. Колодки: диск — подушка ≥ 1 мм (с холдером ≥ 3 мм); обод — до канавок износа.
        ЕСЛИ изношены → ВЫЗОВ Замена тормозных колодок() [BRK-03] / замена ободных.
   1.3. Трос и рубашка на заломы, коррозию. ЕСЛИ повреждены → ВЫЗОВ Замена
        тормозного троса() [BRK-06].
   1.4. Диск: биение ротора. ЕСЛИ есть → ВЫЗОВ Замена или правка ротора() [BRK-07].

2. ЕСЛИ механический диск:
   2.1. Отпустить трос (ослабить фиксирующий болт).
   2.2. Винтами подвода придвинуть обе колодки к ротору до касания
        (Avid: обе ручки подводить одинаковым числом кликов — соотношение 2:1).
   2.3. Отвести неподвижную колодку до зазора ≈ 0.2–0.3 мм, подвижную — до
        рабочего зазора.
   2.4. Центровать корпус суппорта: ослабить болты крепления, зажать рычаг,
        подтянуть болты, отпустить рычаг, крутить колесо — трения нет →
        затянуть болты 6–8 Н·м.
   2.5. Подвести лапку троса, выбрать слабину, зафиксировать болтом с моментом.
   2.6. Барабанчиком выставить свободный ход ручки.

3. ЕСЛИ ободные:
   3.1. Колодки по центру рабочей поверхности обода: не задевают покрышку
        (зазор сверху ≈ 1 мм), не свисают за обод.
   3.2. Затянуть болты колодок моментом.
   3.3. Натянуть трос через натяжитель, зазор колодка–обод ≈ 1 мм с каждой
        стороны, зафиксировать болтом.
   3.4. Винтом центровки пружины выровнять зазоры слева и справа.
   3.5. Барабанчиком выставить свободный ход.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - ручка не доходит до грипсы, есть свободный ход;
  - колесо крутится без трения;
  - торможение уверенное; при сильном зажатии колесо не провернуть с усилием.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - тип тормоза; заменённые колодки / трос;
  - моменты затяжки; выставленный свободный ход.
```

### ФУНКЦИЯ Настроить гидравлические тормоза(центровка суппорта, подводка колодок)

```
Код операции : BRK-02
Вход         : велосипед на стойке; система герметична (прокачка не требуется)
Инструмент   : шестигранники / Torx, динамометрический ключ, фонарь (подсветить
               суппорт), приспособление для разведения поршней (PP-1.2)
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Убедиться, что колесо село в дропаутах: ослабить ось, придавить велосипед,
        затянуть.
   1.2. Исключить прочие причины трения:
          - погнутый ротор → ВЫЗОВ Замена или правка ротора() [BRK-07];
          - люфт ротора (болты / lockring);
          - люфт втулки (покачать колесо вбок);
          - залипшие поршни от грязи.
   1.3. Остаток колодок ≥ 1 мм.

2. ЦЕНТРОВКА:
   2.1. Ослабить оба болта крепления суппорта — суппорт ходит вбок.
   2.2. Зажать рычаг тормоза — суппорт центруется по ротору.
   2.3. Удерживая рычаг, слегка подтянуть болты.
   2.4. Отпустить рычаг, крутить колесо — проверить трение.
   2.5. ЕСЛИ трения нет → затянуть болты 6–8 Н·м.
        ИНАЧЕ → на вращающемся колесе ослабить один болт, сдвинуть суппорт от
        стороны задевания до равного зазора, затянуть.

3. ЕСЛИ поршни залипают:
   3.1. Снять колодки, почистить видимую часть поршней и полость спиртом.
   3.2. Равномерно выдвинуть/задвинуть поршни несколько раз.
   3.3. ЕСЛИ не помогло → ВЫЗОВ Обслуживание тормозного суппорта() [BRK-08].

4. ПОДВОДКА КОЛОДОК: ЕСЛИ ход ручки большой → несколько раз прожать рычаг,
   поршни выйдут на рабочую позицию.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - колесо крутится свободно, без шороха;
  - ручка не проваливается к грипсе;
  - торможение уверенное.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - момент болтов суппорта; чистились ли поршни.
```

ЗАМЕТКА: клиновидные разводные приспособления не применять на керамических
поршнях (дорожные дисковые тормоза Shimano).

ИСТОЧНИК: Park Tool, Hydraulic Disc Brake Alignment — https://www.parktool.com/en-us/blog/repair-help/hydraulic-disc-brake-alignment

### ФУНКЦИЯ Заменить тормозные колодки(дисковые, пара)

```
Код операции : BRK-03
Вход         : велосипед на стойке
Инструмент   : шестигранники / Torx, плоскогубцы, приспособление для поршней
               (PP-1.2) или неметаллический рычаг, спирт, ветошь, динамометрический ключ
Расходники   : колодки под модель суппорта
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Подобрать колодки по форме под модель суппорта.
   1.2. Осмотреть старые на замасливание (писк, тёмный мажущийся след на роторе).
        ЕСЛИ замаслены → ротор обезжирить или заменить, иначе новые колодки
        тоже загрязнятся.

2. Снять колесо.

3. СНЯТЬ СТАРЫЕ КОЛОДКИ:
   3.1. Вынуть шплинт / стопор, открутить фиксирующий болт (если есть).
   3.2. Извлечь колодки с пружиной; запомнить ориентацию пружины.

4. СБРОСИТЬ ПОРШНИ:
   4.1. Почистить видимую часть поршней и полость спиртом.
   4.2. Вдавить поршни полностью в корпус (PP-1.2 либо неметаллический рычаг;
        НЕ клиновидный инструмент для керамических поршней).

5. УСТАНОВИТЬ НОВЫЕ: собрать с пружиной, вставить, затянуть фиксирующий болт,
   поставить шплинт / стопор.

6. Поставить колесо, несколько раз прожать рычаг до плотного контакта колодок.

7. ВЫЗОВ Настроить гидравлические тормоза() [BRK-02].

8. ПРИКАТКА: 15–20 разгонов и торможений до умеренной скорости без полной
   остановки.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - трения нет; ручка плотная;
  - после прикатки торможение уверенное, ровное.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель колодок; состояние ротора; выполнена ли прикатка.
```

ИСТОЧНИК: Park Tool, Disc Brake Pad Removal & Installation — https://www.parktool.com/en-us/blog/repair-help/disc-brake-pad-removal-installation

### ФУНКЦИЯ Прокачать гидравлические тормоза(контур: передний | задний)

```
Код операции : BRK-04
Вход         : велосипед на стойке
Инструмент   : набор для прокачки под жидкость (Shimano — минеральное масло;
               SRAM — DOT), нужная жидкость, перчатки и очки, спирт, ветошь,
               Torx / hex, транспортировочная проставка в суппорт
```

```
ТБ: DOT едкий, портит краску и пластик; минеральное масло убирать сразу тоже.
НИКОГДА не смешивать DOT и минеральное. Работать в перчатках и очках.

1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить систему и тип жидкости по маркировке на бачке / рычаге.
   1.2. Признаки: ручка проваливается или пружинит, ход растёт, «губчатость».

2. ПОДГОТОВКА:
   2.1. Снять колесо и колодки, вставить проставку в суппорт.
   2.2. Выставить рычаг горизонтально (по мануалу бренда).
   2.3. Защитить раму и ротор от жидкости.

3. ПРОКАЧКА (принцип; детали строго по мануалу бренда):
   3.1. ЕСЛИ Shimano → воронка сверху на рычаге, шприц снизу у суппорта; гнать
        жидкость снизу вверх, простукивая линию и суппорт, выгоняя пузыри в
        воронку; закрыть ниппель моментом; снять воронку с пробкой.
   3.2. ЕСЛИ SRAM → два шприца (рычаг и суппорт, Bleeding Edge); чередовать
        давление и разрежение, «pull-and-push», убрать пузыри; закрыть
        Bleeding Edge, затем рычаг; моменты болтов.

4. ФИНАЛ: протереть всё спиртом; поставить колодки и колесо;
   ВЫЗОВ Настроить гидравлические тормоза() [BRK-02].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - ручка плотная, ход стабильный, точка схватывания чёткая;
  - у ниппелей и штуцеров нет подтёков (зажать и подержать под нагрузкой);
  - торможение уверенное.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - система, тип жидкости, контур(ы);
  - прокачка частичная или полная замена жидкости.
```

### ФУНКЦИЯ Заменить гидролинию(объём: укоротить | заменить целиком)

```
Код операции : BRK-05
Вход         : велосипед на стойке
Инструмент   : инструмент реза и запрессовки штуцера (HBT-1) либо нож для
               гидролинии + запрессовка оливки, штуцеры / оливки / накидные гайки
               под бренд, ключи, набор для прокачки
Расходники   : гидролиния (при полной замене), фитинги, жидкость
```

```
ТБ: система вскрывается → прокачка обязательна. Инструмент HBT-1 не режет
линию со стальной оплёткой.

1. ВХОДНОЙ КОНТРОЛЬ: бренд и модель — оливка и штуцер строго под систему.

2. ЕСЛИ укоротить → определить новую длину: руль крутится свободно, плавная
   дуга, вход в рычаг по прямой.

3. Освободить линию с той стороны, где укорачиваем (у рычага или у суппорта);
   подставить ёмкость, потери жидкости минимизировать.

4. ОБРЕЗАТЬ линию в инструменте строго ровно.

5. УСТАНОВИТЬ ФИТИНГИ:
   5.1. Надеть накидную гайку и компрессионное кольцо (оливку) на линию.
   5.2. Наживить штуцер (barb) от руки, затем запрессовать заподлицо с торцом.

6. СОБРАТЬ: вставить в приёмник, затянуть накидную гайку моментом по спецификации.

7. ВЫЗОВ Прокачать гидравлические тормоза() [BRK-04].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - под нагрузкой (зажать и подержать) подтёков нет;
  - ручка плотная; линия не мешает рулю.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - укорочение или полная замена; бренд фитингов; момент гайки; прокачка выполнена.
```

ИСТОЧНИК: Park Tool, HBT-1 Hydraulic Barb Tool — https://www.parktool.com/en-us/product/hydraulic-barb-tool-hbt-1

### ФУНКЦИЯ Заменить тормозной трос(механика)

```
Код операции : BRK-06
Вход         : велосипед на стойке
Инструмент   : кусачки для тросов и намотанной рубашки, натяжитель троса,
               шестигранники, динамометрический ключ
Расходники   : тормозной трос, при необходимости тормозная рубашка, наконечники
```

```
1. ВХОДНОЙ КОНТРОЛЬ: тип рычага — drop-bar (наконечник «грибок» / «капля»);
   плоский руль (наконечник «бочонок»). НЕ использовать тонкую переключательную
   рубашку под тормоз — может разрушиться.

2. Снять старый трос в положении отпущенного рычага.

3. ЕСЛИ менять рубашку:
   3.1. Взять намотанную (wound) или кевларовую тормозную рубашку.
   3.2. Резать как можно короче при прямом входе в упоры и барабанчики.
   3.3. Намотанную резать у края губок кусачек; торец выровнять; колпачок.

4. ПРОДЕТЬ новый трос: правильный наконечник в рычаг, по рубашкам,
   зафиксировать болтом с моментом.

5. ПРЕДВАРИТЕЛЬНОЕ РАСТЯЖЕНИЕ: прожать рычаг несколько раз, обжать рубашки,
   дотянуть болт.

6. ВЫЗОВ Настроить механические тормоза() [BRK-01].

7. Обрезать трос 3–4 см, наконечник.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - ход ручки правильный, торможение уверенное;
  - наконечники на тросе и рубашках установлены.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - трос / трос + рубашка; тип; момент болта.
```

### ФУНКЦИЯ Заменить или отправить ротор(действие: правка | замена)

```
Код операции : BRK-07
Вход         : велосипед на стойке
Инструмент   : правочная вилка (DT-2.2) или ключ с гладкими губками, фонарь,
               Torx T25 (6 болтов) или съёмник lockring (BBT-9 / FR-5.2 —
               по типу насечек), перчатки, спирт, динамометрический ключ
Расходники   : ротор нужного диаметра (при замене), стопорные шайбы / болты
```

```
1. ДИАГНОЗ:
   1.1. Крутить колесо, смотреть биение ротора в просвете колодок (подсветить).
   1.2. Отметить зоны, куда ротор уходит.
   1.3. Замерить толщину рабочей поверхности, сравнить с новым: износ ~0.2–0.4 мм
        и более → замена.

2. ЕСЛИ сильный изгиб от удара ИЛИ износ по толщине → ЗАМЕНА:
   2.1. Определить крепление: 6 болтов (Torx T25) или Center Lock (стопорное
        кольцо — под внешние насечки BBT-9 / BBT-69.4, под внутренние — FR-5.2).
   2.2. Снять старый; поставить новый нужного диаметра, не касаясь поверхности
        руками.
   2.3. 6 болтов — крест-накрест с моментом (обычно ~4–6 Н·м);
        Center Lock — кольцо с моментом (обычно ~40 Н·м).

3. ЕСЛИ лёгкая поводка → ПРАВКА:
   3.1. Правочной вилкой захватывать ротор в зоне ухода, гнуть малыми движениями
        в обратную сторону.
   3.2. Перепроверять по просвету колодок после каждого движения.
   3.3. ЕСЛИ за несколько минут нет улучшения → ротор под замену.

4. ВЫЗОВ Настроить гидравлические тормоза() [BRK-02] ИЛИ
   Настроить механические тормоза() [BRK-01].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - биение в пределах просвета колодок, трения нет;
  - при замене — момент крепежа соблюдён, поверхность обезжирена.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - правка или замена; диаметр и модель ротора; тип крепления и момент.
```

### ФУНКЦИЯ Обслужить тормозной суппорт()

```
Код операции : BRK-08
СТАТУС       : черновик — детали по мануалу конкретного бренда (Park Tool не имеет
               отдельной статьи по замене уплотнений суппорта).
Вход         : велосипед на стойке; есть ремкомплект под модель
Инструмент   : набор для прокачки, чистая жидкость, пластиковый инструмент для
               уплотнений, спирт, перчатки и очки, динамометрический ключ
Расходники   : уплотнительные кольца и пыльники под модель, при износе — поршни
```

```
1. ВХОДНОЙ КОНТРОЛЬ: показания — поршни залипают и не лечатся внешней чисткой,
   подтёки жидкости из корпуса, неравномерный износ колодок, «уезжающая» точка
   схватывания. Наличие ремкомплекта под модель.

2. Снять суппорт, слить жидкость в ёмкость, снять колодки.

3. ВЫДВИНУТЬ ПОРШНИ равномерно (рычагом манетки или малым давлением воздуха;
   тряпку под поршни — риск вылета). Разрезной суппорт — разъединить половины.

4. РАЗБОРКА: извлечь поршни; снять пыльники и уплотнительные кольца из канавок
   пластиковым инструментом, не царапая канавки.

5. ЧИСТКА: канавки и поршни спиртом / чистой жидкостью; осмотр поршней на
   коррозию и сколы (керамика — особенно). Задиры → поршень под замену.

6. СБОРКА: новые кольца и пыльники, смазать рекомендованной жидкостью / смазкой,
   вставить поршни без перекоса; собрать половины с моментом.

7. Установить суппорт; ВЫЗОВ Прокачать гидравлические тормоза() [BRK-04];
   ВЫЗОВ Настроить гидравлические тормоза() [BRK-02].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - поршни выходят и возвращаются равномерно;
  - под нагрузкой подтёков нет; ручка плотная.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - заменены уплотнения / поршни; модель ремкомплекта; выполнена прокачка.
```
