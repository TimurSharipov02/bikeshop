### ФУНКЦИЯ Настроить задний переключатель(тип: механика)

```
Код операции : DRV-01
Вход         : велосипед на стойке; трансмиссия в приемлемом износе
Инструмент   : отвёртка PH2 / плоская, шестигранники, натяжитель троса,
               кусачки, динамометрический ключ
Расходники   : лёгкая смазка, наконечник троса, ветошь
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Проверить ровность петуха.
        ЕСЛИ погнут → ВЫЗОВ Юстировка петуха() [DRV-07], затем вернуться сюда.
   1.2. Замерить износ цепи.
        ЕСЛИ цепь ≥ 0.75 % → предупредить клиента: на изношенной трансмиссии
        чёткой настройки не будет; предложить замену (DRV-03 / DRV-04).
   1.3. Осмотреть трос и рубашку: заломы, коррозия, лохмы.
        ЕСЛИ повреждены → ВЫЗОВ Замена троса переключения() [DRV-06], затем сюда.
   1.4. Проверить ролики переключателя на люфт и износ.

2. H-ЛИМИТ (верхний упор, малая звезда):
   2.1. Цепь на большую звезду системы и самую малую звезду кассеты; убедиться,
        что манетка отработала до конца (щелчков не осталось).
   2.2. Ослабить болт крепления троса — снять натяжение.
   2.3. Вращая педали, закручивать винт H, ПОКА цепь не начнёт шуметь о 2-ю звезду.
   2.4. ПОКА слышен шум ПОВТОРЯТЬ: отпускать H на 1/4 оборота.
   2.5. ЕСЛИ два положения одинаково тихие → выбрать более затянутое.
   ПРОВЕРИТЬ: верхний ролик под самой малой звездой, цепь не задевает рамку.

3. НАТЯЖЕНИЕ ТРОСА И ИНДЕКСАЦИЯ:
   3.1. Барабанчик регулятора закрутить до упора, отпустить на 1 оборот.
   3.2. Рукой выбрать слабину троса, зафиксировать болтом с моментом по
        спецификации (обычно 5–7 Н·м).
   3.3. Вращая педали, переключить на 1 щелчок вверх (2-я звезда).
        ЕСЛИ цепь не перешла → барабанчик на 1 полный оборот против часовой.
        ЕСЛИ перескочила через передачу → барабанчик на 1 оборот по часовой.
   3.4. ДЛЯ КАЖДОЙ звезды (снизу вверх, затем сверху вниз):
          вращая педали, слушать шум; барабанчиком по 1/4 оборота убирать шум.
        КОНЕЦ ДЛЯ
   ПРОВЕРИТЬ: чёткое переключение по всей кассете в обе стороны без задержек.

4. L-ЛИМИТ (нижний упор, большая звезда):
   4.1. Встать на 2-ю сверху звезду, переключить на самую большую.
   4.2. ЕСЛИ переход медленный или шумный → винт L перетянут: отпускать по
        1/4 оборота, ПОКА переход не станет чистым.
   ПРОВЕРИТЬ: на самой большой звезде переключатель не уходит в спицы, есть запас.

5. B-ВИНТ (зазор ролика):
   5.1. Цепь на малой звезде системы и большой звезде кассеты.
   5.2. Замерить зазор между верхним роликом и зубьями большой звезды.
        Норма — 5–6 мм (шоссе и МТБ).
   5.3. Закручивать B → зазор больше; отпускать → меньше. Выставить в норму.

6. ЗАВЕРШЕНИЕ:
   6.1. Обрезать трос, оставив 3–4 см, установить наконечник.
   6.2. Капля смазки на трос у входов в рубашку, протереть.
   6.3. Смахнуть стружку троса.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чёткое переключение по всем передачам вверх/вниз на стенде под нагрузкой;
  - на крайней малой цепь не трётся о рамку переключателя;
  - на крайней большой сохранён запас до спиц;
  - зазор B-винта 5–6 мм на большой звезде;
  - барабанчик регулятора не в крайнем положении;
  - трос закреплён нужным моментом, наконечник на месте.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - фактическое время;
  - износ цепи на входе (%);
  - заменённые расходники;
  - если вызывались DRV-06 / DRV-07 — отдельными операциями;
  - момент затяжки болта троса.
```

### ФУНКЦИЯ Настроить передний переключатель(тип: 2x | 3x)

```
Код операции : DRV-02
Вход         : велосипед на стойке; задний переключатель настроен (DRV-01)
Инструмент   : шестигранники, отвёртка PH2 / плоская, натяжитель троса, кусачки,
               динамометрический ключ, линейка / штангенциркуль
Расходники   : лёгкая смазка, наконечник троса, ветошь
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить тип крепления: хомут / braze-on / direct mount; 2x или 3x.
   1.2. Осмотреть трос и рубашку. ЕСЛИ повреждены → ВЫЗОВ Замена троса
        переключения() [DRV-06], затем сюда.
   1.3. Осмотреть рамку переключателя на износ и деформацию.

2. ВЫСОТА:
   2.1. Внешнюю пластину рамки выставить прямо над большой звездой.
   2.2. Зазор между зубьями большой звезды и нижним краем рамки — 1–2 мм
        (толщина монеты).
   2.3. Ослабить хомут, выставить высоту, затянуть моментом по спецификации.

3. УГОЛ (ротация):
   3.1. Цепь на большую звезду спереди и малую сзади.
   3.2. Смотреть строго сверху: внешняя пластина рамки параллельна цепи.
   3.3. ЕСЛИ не параллельна → ослабить трос, ослабить хомут, довернуть, затянуть.

4. L-ЛИМИТ (внутренний упор):
   4.1. Цепь на малую звезду спереди и большую сзади.
   4.2. Зазор внутренняя пластина — цепь ≈ 1 мм (1/16″).
   4.3. Винт L по 1/8 оборота: цепь не трёт, но быстро сбрасывается на малую.
        ЕСЛИ цепь падает внутрь → L затянуть.

5. НАТЯЖЕНИЕ ТРОСА:
   5.1. Барабанчик (если есть) закрутить, отпустить на 1 оборот.
   5.2. Выбрать слабину троса рукой, зафиксировать болтом с моментом.

6. H-ЛИМИТ (внешний упор):
   6.1. Цепь на большую звезду спереди и малую сзади.
   6.2. Подтянуть трос рукой до полного упора рамки в винт H.
   6.3. Зазор цепь — внешняя пластина ≈ 1 мм. Винт H по 1/8 оборота: не трёт и
        не перебрасывает за звезду.

7. ИНДЕКСАЦИЯ:
   7.1. ЕСЛИ 2 звезды → цепь на большую спереди и большую сзади; барабанчик
        против часовой, ПОКА не уйдёт трение (не доводя до трения с другой стороны).
   7.2. ЕСЛИ 3 звезды → цепь на среднюю спереди и малую сзади; барабанчиком
        минимизировать зазор без трения; проверить все 3 звезды.

8. ЗАВЕРШЕНИЕ: обрезать трос, наконечник, капля смазки, убрать стружку.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чёткий сброс и подъём по всем звёздам системы под нагрузкой;
  - на рабочих комбинациях передач трения цепи о рамку нет;
  - на перекрёстных (большая-большая, малая-малая) лёгкое трение допустимо.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - фактическое время; заменённые расходники;
  - момент затяжки хомута и болта троса;
  - если вызывался DRV-06 — отдельной операцией.
```

ЗАМЕТКА: перекрёстные передачи не рабочие — лёгкое трение на них не дефект.

ИСТОЧНИК: Park Tool, Front Derailleur Adjustment — https://www.parktool.com/en-us/blog/repair-help/front-derailleur-adjustment

### ФУНКЦИЯ Заменить цепь(тип трансмиссии: 1x | 2x | 3x)

```
Код операции : DRV-03
Вход         : велосипед на стойке
Инструмент   : выжимка цепи, съёмник замка, измеритель износа, кусачки, ветошь
Расходники   : цепь нужной скорости и совместимости, замок / соединительный пин
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить совместимость: число скоростей, бренд трансмиссии
        (Shimano / SRAM / Campagnolo), тип соединения.
   1.2. ВЫЗОВ Диагностика износа трансмиссии() [DRV-09].
        ЕСЛИ кассета / звёзды изношены → новая цепь будет проскакивать →
        СОГЛАСОВАТЬ С КЛИЕНТОМ замену кассеты [DRV-04] и/или звёзд [DRV-05].

2. СНЯТЬ СТАРУЮ ЦЕПЬ:
   2.1. Переключить на малую звезду спереди и малую сзади.
   2.2. ЕСЛИ стоит замок → расстегнуть съёмником.
        ИНАЧЕ → выдавить любой пин выжимкой.
   2.3. Сохранить старую цепь для сверки длины.

3. ПОДОБРАТЬ ДЛИНУ (метод Park Tool):
   3.1. ЕСЛИ 2x/3x и самая большая звезда кассеты ≤ 36T:
          обвести цепь вокруг большой звезды системы и большой звезды кассеты,
          МИНУЯ задний переключатель; продеть через передний переключатель;
          найти ближайший стык (внутренняя пластина к внешней);
          ДОБАВИТЬ ровно 2 пина от этой точки — здесь резать.
   3.2. ЕСЛИ 1x и большая звезда кассеты ≥ 42T:
          обвести вокруг звезды и большой звезды кассеты, минуя переключатель;
          найти стык; ДОБАВИТЬ 4 пина (2 дюйма) — здесь резать.
   3.3. ЕСЛИ полная подвеска → отсоединить / разгрузить амортизатор, сжать
        подвеску до конца хода, затем мерить.
   3.4. Проверка через переключатель: на большой-большой цепи хватает с двумя
        изгибами на роликах; на малой-малой цепь не провисает до касания ролика.

4. УКОРОТИТЬ И СОЕДИНИТЬ:
   4.1. Выжимкой удалить лишние звенья, соблюдая чередование пластин
        (внутренняя соединяется с внешней).
   4.2. Продеть цепь по всей трансмиссии, через задний переключатель правильно
        (над верхним роликом, по направляющей рамки).
   4.3. Соединить:
          - замок → защёлкнуть, дожать педалированием под тормозом;
          - пин Shimano → запрессовать с направляющим штифтом, отломить штифт,
            размять звено, убедиться, что оно не тугое.

5. ПРОВЕРКА: прогнать по всем передачам; тугих звеньев нет; на малой-малой
   цепь не бьёт по нижнему ролику.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - длина верна по обеим крайним комбинациям;
  - соединение выполнено штатным способом, звено подвижно;
  - переключение по всей кассете чистое.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель цепи, итоговое число звеньев;
  - износ на входе (%); тип соединения (замок / пин);
  - если менялись кассета / звёзды — отдельными операциями.
```

### ФУНКЦИЯ Заменить кассету()

```
Код операции : DRV-04
Вход         : велосипед на стойке
Инструмент   : хлыст цепной, съёмник стопорного кольца + большой ключ,
               динамометрический ключ, ветошь
Расходники   : кассета нужного типа, лёгкая смазка
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить тип: Shimano HG, SRAM XD/XDR, Shimano Micro Spline, Campagnolo.
        Съёмник должен точно подходить, иначе повредит и съёмник, и деталь.
   1.2. Снять заднее колесо, вынуть эксцентрик / ось.

2. СНЯТЬ:
   2.1. Вставить съёмник в стопорное кольцо, цепным хлыстом держать кассету:
        хлыст на 9 часов, ключ съёмника на 3 часа, давить вниз.
   2.2. При страгивании слышен треск стопорных зубьев кольца — это норма.
   2.3. Снять кольцо, снять звёзды по порядку, запоминая проставки и ориентацию
        (широкий шлиц = единственное положение).

3. ОСМОТР БАРАБАНА:
   3.1. Проверить шлицы барабана на задиры от старой кассеты.
   3.2. Почистить; тонкий слой смазки на шлицы (по регламенту втулки).

4. УСТАНОВИТЬ:
   4.1. Совместить широкий шлиц барабана с широким шлицем кассеты.
   4.2. Собрать звёзды и проставки в исходном порядке.
   4.3. Лёгкая смазка на резьбу кольца; наживить, затянуть моментом
        (Shimano HG ≈ 40 Н·м; XD/XDR — по спецификации SRAM).

5. ПРОВЕРКА: осевого люфта кассеты нет; после установки колеса — прогнать
   переключение, при необходимости подстроить индексацию барабанчиком.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - кассета без люфта, кольцо затянуто моментом;
  - переключение по всей кассете чистое.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель кассеты, момент затяжки кольца, состояние барабана.
```

### ФУНКЦИЯ Заменить систему или звёзды(объём: только звёзды | система целиком)

```
Код операции : DRV-05
Вход         : велосипед на стойке
Инструмент   : шестигранники / Torx, инструмент снятия шатунов по типу (см. bb.md),
               инструмент для стопорного кольца звезды, динамометрический ключ
Расходники   : фиксатор резьбы / монтажная паста по спецификации, смазка
```

```
1. ОПРЕДЕЛИТЬ ТИП КРЕПЛЕНИЯ ШАТУНОВ:
   - левый шатун с компрессионным клином (2 пинч-болта) + крышка предзатяга
     → компрессионный клин (Hollowtech II / FSA);
   - в торце шатуна резьба под съёмник, болт по центру, отдельный пыльник
     → трёхкомпонентные (съёмником);
   - болт с несъёмным стопорным кольцом по центру → самосъёмный болт;
   - звёзды могут быть direct-mount или со стопорным кольцом (часто e-bike).

2. СНЯТЬ ШАТУНЫ: ВЫЗОВ соответствующей вспомогательной функции снятия шатунов
   (см. `bb.md`) — компрессионный клин / съёмником / самосъёмный болт.

3. ЕСЛИ объём = только звёзды:
   3.1. Открутить болты звёзд, придерживая гайку с обратной стороны.
   3.2. Запомнить ориентацию (метка / штифт напротив шатуна — для сброса цепи).
   3.3. Поставить новые: на резьбу — фиксатор или паста по спецификации,
        затянуть моментом крест-накрест.
   3.4. Direct-mount / стопорное кольцо — штатным инструментом и моментом.

4. ПОСТАВИТЬ ШАТУНЫ: ВЫЗОВ той же вспомогательной функции (установка).
   Проверить осевой люфт и свободное вращение.

5. ПРОВЕРКА: люфта каретки нет; шатуны крутятся свободно, без хруста; звёзды
   без биения.
   ЕСЛИ менялся размер звёзд → ВЫЗОВ Настроить передний переключатель() [DRV-02].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - все моменты затяжки соблюдены;
  - нет люфта и посторонних звуков при вращении;
  - передний переключатель перенастроен при изменении размера звёзд.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - тип системы, модель звёзд / системы;
  - моменты затяжки; применён ли фиксатор резьбы.
```

### ФУНКЦИЯ Заменить трос переключения(что менять: трос | трос и рубашка)

```
Код операции : DRV-06
Вход         : велосипед на стойке
Инструмент   : кусачки для тросов и рубашек, натяжитель троса, шестигранники,
               отвёртка, шило, динамометрический ключ
Расходники   : трос переключения, при необходимости рубашка, наконечники троса
               и рубашки
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить тип манетки: drop-bar (STI) / триггер / грипшифт / бар-энд.
   1.2. Проводка внешняя или внутренняя (через раму).

2. СНЯТЬ СТАРЫЙ ТРОС:
   2.1. Переключить манетку в положение наименьшего натяжения.
   2.2. Ослабить фиксирующий болт, вытащить трос из манетки.
   2.3. ЕСЛИ внутренняя проводка → перед вытягиванием протянуть направляющую
        леску / тросик-проводник, чтобы сохранить канал.

3. ЕСЛИ что менять = трос и рубашка:
   3.1. Нарезать новые куски по длине старых или проложить заново: плавные дуги,
        руль поворачивается без натяга и провисания.
   3.2. Рез строго перпендикулярно; торец выровнять; надеть колпачок; проколоть
        лайнер шилом.

4. ПРОДЕТЬ НОВЫЙ ТРОС:
   4.1. Завести в манетку в положении полного отпуска.
   4.2. Продеть по рубашкам и упорам рамы.
   4.3. Зафиксировать болтом с моментом по спецификации.

5. ПРЕДВАРИТЕЛЬНОЕ РАСТЯЖЕНИЕ:
   5.1. Несколько раз прощёлкать весь диапазон, обжать рубашки в упорах.
   5.2. Заново выбрать слабину, дотянуть болт.

6. ВЫЗОВ Настроить задний переключатель() [DRV-01]
   ИЛИ Настроить передний переключатель() [DRV-02] — по тому, какой трос менялся.

7. ЗАВЕРШЕНИЕ: обрезать трос 3–4 см, наконечник, убрать стружку.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - переключение по всему диапазону чистое, без задержек;
  - рубашки лежат плавно, руль крутится свободно;
  - наконечники на тросе и рубашках установлены.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - заменён трос / трос + рубашка; тип; момент болта.
```

### ФУНКЦИЯ Отъюстировать петух()

```
Код операции : DRV-07
Вход         : велосипед на стойке, колёса горизонтально
Инструмент   : калибр петуха (DAG-2.2 / DAG-3), шестигранники, 3 мм шестигранник
               как щуп «годен / не годен»
```

```
1. ПОДГОТОВКА:
   1.1. Заднее колесо строго ровно в дропаутах.
   1.2. Снять задний переключатель, вкрутить калибр в петух, затянуть ручку.
   1.3. ЕСЛИ резьба повреждена → ВЫЗОВ Восстановление резьбы() [FRM-05] до юстировки.
   1.4. Ниппель камеры повернуть на 3 часа — это точка отсчёта (убирает влияние
        зонта и восьмёрки колеса).

2. ГОРИЗОНТАЛЬ (3 и 9 часов):
   2.1. Подвести индикатор калибра к ободу на 3 часах, зафиксировать зазор.
   2.2. Повернуть калибр на 9 часов (180°), к той же точке обода.
   2.3. Величина ошибки = ПОЛОВИНА зазора между индикатором и ободом.
   2.4. ПОКА зазор > 3 мм ПОВТОРЯТЬ: гнуть малым усилием (рычаг калибра у пера
        рамы), перепроверять обе точки.

3. ВЕРТИКАЛЬ (6 и 12 часов): то же правило половины зазора; свести к < 3 мм.

4. КОНТРОЛЬ: четыре точки через 90° все в пределах 3 мм.

5. ЕСЛИ петух ранее многократно гнули ИЛИ чувствуется трещина / «пружинит» →
   СТОП, СОГЛАСОВАТЬ С КЛИЕНТОМ замену петуха (риск облома при юстировке).
   Интегрированный петух (карбон) — крайняя осторожность, замена невозможна.

6. Установить задний переключатель, ВЫЗОВ Настроить задний переключатель() [DRV-01].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - 4 точки в пределах 3 мм;
  - индексация после юстировки чистая.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - примерная величина «было»; гнули или заменили петух.
```

ИСТОЧНИК: Park Tool, Rear Derailleur Hanger Alignment — https://www.parktool.com/en-us/blog/repair-help/rear-derailleur-hanger-alignment

### ФУНКЦИЯ Настроить электронную группу(система: Shimano Di2 | SRAM AXS/eTap | другая)

```
Код операции : DRV-08
Вход         : велосипед на стойке; АКБ заряжена (см. EL-02)
Инструмент   : смартфон с приложением (Shimano E-Tube / SRAM AXS), инструмент для
               разъёмов e-tube (для Di2), шестигранники, отвёртка, калибр зазора
               цепи (SRAM chain gap tool), динамометрический ключ
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить систему и поколение.
   1.2. ВЫЗОВ Диагностика электронной группы() [EL-02] — заряд, провода, разъёмы.
   1.3. Прошивка актуальна? При сомнении → ВЫЗОВ Обновить прошивку() [EL-01].
   1.4. Проверить ровность петуха; погнут → ВЫЗОВ Отъюстировать петух() [DRV-07].

2. ЛИМИТЫ И B-ЗАЗОР (механическая база — как у механики):
   2.1. Shimano Di2: H-винт — на самой малой звезде, L-винт — на самой большой;
        B-винт — зазор верхнего ролика до большой звезды по спецификации.
   2.2. SRAM AXS: выставить положение переключателя установочным ключом (setup);
        H / L винты; B-зазор — калибром зазора цепи (chain gap tool) на большой
        и малой звезде.

3. МИКРОНАСТРОЙКА ИНДЕКСАЦИИ:
   3.1. Shimano Di2: нажать кнопку на блоке/дисплее один раз — загорится индикатор
        режима регулировки. Каждое нажатие манетки = смещение ролика ~0.2 мм
        (всего 12 шагов, диапазон ~4.8 мм). Довести до бесшумной работы на всех
        звёздах, выйти из режима.
   3.2. SRAM AXS: удерживать паддл манетки и коротко нажимать кнопку AXS на
        переключателе — 1 нажатие = 1 шаг (~0.2 мм); влево/вправо разными
        кнопками. Довести до тишины на всех звёздах.
   3.3. Либо микронастройка из приложения.

4. ПЕРЕДНИЙ ПЕРЕКЛЮЧАТЕЛЬ:
   4.1. Di2: авто-тримминг работает сам; выставить лимиты и высоту/угол рамки.
   4.2. AXS: выставить рамку по установочному инструменту, лимиты, проверить
        сброс/подъём.

5. ЕСЛИ система = другая (FSA WE, Campagnolo EPS) → СТАТУС: заглушка, вести строго
   по мануалу производителя (ссылки в `el.md`).

6. ПРОВЕРКА на стенде: чёткое переключение по всей кассете в обе стороны под
   нагрузкой.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - переключение без задержек по всему диапазону под нагрузкой;
  - лимиты и B-зазор в норме; заряд рабочий;
  - режим регулировки закрыт.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - система и поколение; выполнена ли микронастройка; версия прошивки.
```

### ФУНКЦИЯ Диагностика износа трансмиссии()

```
Код операции : DRV-09
Вход         : велосипед на стойке
Инструмент   : измеритель износа цепи (CC-4.2), фонарь
```

```
1. ЦЕПЬ:
   1.1. Опустить измеритель на цепь, держа кончик над цепью; дать натяг короткой
        секции (обязательно для точности).
   1.2. Считать порог: 0.5 % / 0.75 % / 1.0 %.
        ЕСЛИ ≥ 0.5 % (11–12 скоростей) ИЛИ ≥ 0.75 % (более широкие цепи)
          → менять цепь.
        ЕСЛИ ≥ 1.0 % → почти наверняка потребуется и кассета.

2. КАССЕТА: прокрутить назад под нагрузкой рукой — ЕСЛИ (после установки новой
   цепи) на рабочих звёздах цепь проскакивает → кассета изношена. Осмотр зубьев:
   «акулий плавник», подрез.

3. ЗВЁЗДЫ СИСТЕМЫ: осмотр на крючкообразный / асимметричный износ зубьев (чаще
   изнашивается рабочая звезда).

4. РОЛИКИ ПЕРЕКЛЮЧАТЕЛЯ: люфт, острые зубья, заедание.

5. ВЫВОД: сформировать рекомендацию — что менять сейчас, что в ближайшее ТО.
```

```
ЗАМЕТКА: правило экономии — вовремя менять цепь дешевле, чем позже цепь + кассету
(+ звёзды).
ФИКСИРОВАТЬ В НАРЯДЕ:
  - износ цепи (%); вердикт по кассете, звёздам, роликам.
```
