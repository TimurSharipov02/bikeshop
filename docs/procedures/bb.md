# Каретка, шатуны, педали (BB)

Функции группы BB. Нотация — в `README.md`.

**Термины:** «кареточный стакан» (или просто «стакан») — участок рамы, куда
ставится каретка; его ширина (68 / 73 мм, Italian, T47) и тип (резьбовой /
press-fit) определяют выбор каретки.

> Направление резьбы каретки (BSA / English): левая (не-приводная) чашка —
> правая резьба (затягивается по часовой); правая (приводная) чашка — левая
> резьба (затягивается против часовой). Italian — обе правая резьба.

Снятие и установка шатунов вынесены в три вспомогательные функции по типу
крепления — их вызывают BB-01, BB-02, BB-04 и DRV-05.

---

### ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ Снять и поставить шатуны — компрессионный клин (Hollowtech II / FSA)

```
Инструмент : инструмент крышки предзатяга (звёздочка Shimano / hex 8–10 мм FSA),
             hex для пинч-болтов, пластиковая киянка, тонкая отвёртка / крючок,
             динамометрический ключ, смазка, антисиз
```

```
СНЯТЬ:
  1. Полностью ослабить оба пинч-болта на левом шатуне.
  2. Инструментом выкрутить крышку предзатяга против часовой.
  3. Shimano: приподнять стопорную пластину-фиксатор тонкой отвёрткой / крючком.
  4. Снять левый шатун с оси руками (при необходимости лёгкий удар киянкой).
  5. Вытащить ось с правым шатуном вправо (при необходимости постучать киянкой по оси).

ПОСТАВИТЬ:
  1. Смазать поверхность оси у правого шатуна, продеть через правую чашку и
     наружу левой.
  2. Смазка на шлицы оси; антисиз на резьбу пинч-болтов.
  3. Правый шатун на 6 часов, левый на 12 часов — надеть на ось;
     Shimano — стопорная пластина заходит над резьбой пинч-болтов.
  4. Смазка / антисиз на резьбу крышки предзатяга, наживить в ось от руки,
     подтянуть до устранения люфта БЕЗ перетяга (пластиковая крышка — момент
     по мануалу, порядка 0.5–1.5 Н·м).
  5. Затянуть пинч-болты, чередуя по 1/2 оборота, равномерно, до 12–15 Н·м.
  6. Проверить: люфта между шатуном и осью нет, вращение свободное.
```

### ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ Снять и поставить шатуны — трёхкомпонентные (съёмником)

```
Применимо  : квадрат (square taper), шлицы ISIS / Octalink
Инструмент : ключ болта шатуна (hex / CCW-5), съёмник шатунов под тип (квадрат —
             малый наконечник; шлицы — большой), динамометрический ключ,
             смазка / антисиз
```

```
СНЯТЬ:
  1. Переключить на большую звезду (защита руки).
  2. Снять пыльник (поддевается или выкручивается).
  3. Открутить болт / гайку шатуна против часовой, вынуть шайбу.
  4. Убедиться, что подвижный шток съёмника полностью вывернут (утоплен в теле).
  5. Вкрутить тело съёмника в резьбу шатуна ДО КОНЦА (неполно — сорвёт резьбу).
  6. Заворачивать шток съёмника по часовой; при упоре в ось усилие растёт;
     продолжать, ПОКА шатун не сойдёт.
  7. Выкрутить съёмник. Повторить со вторым шатуном.

ПОСТАВИТЬ:
  1. Смазка / антисиз под головку и на резьбу болта / гайки.
  2. Квадрат — ось СУХАЯ (без смазки на конус); шлицы — смазать шлицы, один шлиц
     на 12 часов.
  3. Правый шатун вниз (6 часов), надеть, наживить болт.
  4. Затянуть болт шатуна моментом по спецификации (обычно 34–50 Н·м).
  5. Левый шатун строго напротив правого, затянуть так же.
  6. Смазать и поставить пыльник.
  ЗАМЕТКА: на квадрате через 1–2 поездки перепроверить момент — шатун «дотягивается».
```

### ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ Снять и поставить шатуны — с самосъёмным болтом (one-key release)

```
Инструмент : hex болта шатуна, ключ стопорного кольца (штифтовый SPA-2 / SPA-6
             или hex), динамометрический ключ, смазка / антисиз
```

```
КАК РАБОТАЕТ: над болтом шатуна стоит резьбовое стопорное кольцо; при выкручивании
болта его буртик упирается в кольцо и выдавливает шатун с оси — отдельный съёмник
не нужен.

СНЯТЬ:
  1. Убедиться, что стопорное кольцо плотно вкручено в шатун (иначе выкрутится
     только болт, а шатун останется).
  2. Выкручивать болт шатуна hex-ключом, ПОКА шатун не сойдёт с оси.
  3. Снять шатун (при необходимости лёгкий удар киянкой по оси).
  4. Трёхкомпонентная система — повторить с другой стороны.

ПОСТАВИТЬ:
  1. Смазать поверхность оси и резьбу болта.
  2. Надеть первый шатун, совместив шлицы; шайбы / проставки на место.
  3. Наживить болт ровно, затянуть моментом по спецификации.
  4. Второй шатун на 180°, проверить посадку шлицов.
  5. Проверить, что стопорное кольцо плотно затянуто (на будущий демонтаж).
```

### ФУНКЦИЯ Заменить каретку(тип: резьбовая)

```
Код операции : BB-01
Вход         : велосипед на стойке
Инструмент   : съёмник каретки под модель, динамометрический ключ, антисиз
               (ASC-1) или смазка, ветошь
Расходники   : каретка нужного стандарта
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить стандарт стакана: BSA / English 68 / 73, T47, Italian.
   1.2. Определить ось системы: 24 мм (Shimano), 30 мм, 22/24 (DUB).
   1.3. Подобрать каретку и съёмник строго по модели.

2. СНЯТЬ ШАТУНЫ: определить тип крепления и ВЫЗОВ соответствующей вспомогательной
   функции (снятие) — компрессионный клин / съёмником / самосъёмный болт.

3. СНЯТЬ СТАРУЮ КАРЕТКУ:
   3.1. Съёмник вставить до упора, держать строго соосно.
   3.2. Левую (не-приводную) чашку — против часовой.
   3.3. Правую (приводную) чашку — по часовой. Italian — обе против часовой.

4. ПОДГОТОВКА РЕЗЬБЫ:
   4.1. Очистить резьбу стакана; осмотр на срыв, забоины, краску.
   4.2. ЕСЛИ резьба грязная / с наплывами / торцы непараллельны → ВЫЗОВ
        Торцевание посадочных мест каретки() [BB-06].
   4.3. Новые чашки с сухим фиксатором — ставить как есть; иначе антисиз (ASC-1)
        или смазка на резьбу (барьер от коррозии и скрипа, помогает демонтажу).

5. УСТАНОВИТЬ:
   5.1. Наживить от руки на несколько ниток строго ровно (косо — сорвёшь резьбу).
   5.2. Левую чашку затягивать по часовой, правую — против часовой.
   5.3. Затянуть моментом по спецификации (обычно 35–50 Н·м; минимум 35).

6. ПОСТАВИТЬ ШАТУНЫ: ВЫЗОВ той же вспомогательной функции (установка);
   проверить осевой люфт и вращение.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чашки затянуты моментом ≥ 35 Н·м;
  - ось крутится свободно без люфта; под нагрузкой нет скрипа.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - стандарт стакана, модель каретки, момент, антисиз / фиксатор, выполнялось ли
    торцевание.
```

### ФУНКЦИЯ Заменить каретку(тип: press-fit)

```
Код операции : BB-02
Вход         : велосипед на стойке
Инструмент   : выколотка подшипников по диаметру оси (22–24 / 25–28.99 / 30 мм),
               пресс с оправками под стандарт, ретейнер (retaining compound) или
               смазка / антисиз, растворитель, динамометрический ключ
Расходники   : чашки press-fit нужного стандарта
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить стандарт: PF41 (BB86 / BB92), PF42 (BB30 / OSBB), PF46 (PF30),
        Trek BB90 / BB95.
   1.2. Диаметр оси системы; подобрать чашки и инструмент.

2. СНЯТЬ ШАТУНЫ: определить тип крепления и ВЫЗОВ соответствующей вспомогательной
   функции (снятие).

3. ВЫБИТЬ СТАРЫЕ ЧАШКИ / ПОДШИПНИКИ:
   3.1. Инструмент по диаметру оси провести сквозь один подшипник, расклинить
        с обратной стороны.
   3.2. Ударами молотка выбить чашку к противоположной стороне; повторить со второй.

4. ПОДГОТОВКА:
   4.1. Очистить расточку стакана растворителем; осмотр на задиры, овал, износ.
   4.2. Замерить расточку и наружный диаметр чашки — должен быть натяг.
        ЕСЛИ натяг недостаточен → чашки будут двигаться и скрипеть → ставить
        на ретейнер, не на смазку.

5. УСТАНОВИТЬ:
   5.1. Поверхность: смазка / антисиз / ретейнер — по величине натяга и рекомендации.
   5.2. Пресс с оправками точно по стандарту, строго соосно; запрессовать обе
        чашки к центру равномерно.
   5.3. ПРОВЕРИТЬ полное прилегание к торцам стакана (или до нужной глубины по
        мануалу).

6. ПОСТАВИТЬ ШАТУНЫ: ВЫЗОВ той же вспомогательной функции (установка);
   проверить люфт и вращение.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чашки сидят ровно и полностью;
  - ось крутится свободно без люфта; под нагрузкой нет скрипа.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - стандарт, модель чашек, чем ставили (смазка / антисиз / ретейнер),
    состояние расточки.
```

### ФУНКЦИЯ Устранить скрип каретки()

```
Код операции : BB-03
Вход         : велосипед на стойке
Инструмент   : по типу каретки (BB-01 / BB-02), динамометрический ключ,
               антисиз / ретейнер, растворитель
```

```
1. ЛОКАЛИЗАЦИЯ: скрип «отдаёт» в каретку, но источник бывает в педалях, шатунах,
   болтах звёзд, подседеле, седле, рулевой. Проверить очевидное:
   перецепить и протянуть педали, болты звёзд, подседельный штырь.

2. ЕСЛИ подтверждена каретка:
   2.1. РЕЗЬБОВАЯ → снять чашки, очистить резьбу, поставить на антисиз, затянуть
        моментом ≥ 35 Н·м. Частая причина — недотяг.
   2.2. PRESS-FIT → выбить чашки, очистить; ЕСЛИ натяг мал / чашки двигаются →
        переустановить на ретейнер, дать высохнуть.
   2.3. Проверить контакт шатун–ось: паста на шлицы, болт / крышка предзатяга.

3. Проверить, не касается ли системы что-то (цепь, перо, пыльник).
```

```
ПРОВЕРКА КАЧЕСТВА:
  - под нагрузкой (встать на педали, раскачать) скрипа нет.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - найденный источник; что применили (антисиз / ретейнер / момент).
```

### ФУНКЦИЯ Заменить шатуны()

```
Код операции : BB-04
Вход         : велосипед на стойке
Инструмент   : по типу крепления (см. вспомогательные функции), динамометрический
               ключ, смазка / антисиз
Расходники   : шатуны / система
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Совместимость новых шатунов с кареткой (диаметр и длина оси, ширина стакана).
   1.2. Нужная длина шатунов; тип звёзд / BCD; чейнлайн.

2. ОПРЕДЕЛИТЬ ТИП КРЕПЛЕНИЯ:
   - левый шатун с компрессионным клином (2 пинч-болта) + крышка предзатяга
     → компрессионный клин (Hollowtech II / FSA);
   - в торце шатуна резьба под съёмник, болт по центру, отдельный пыльник
     → трёхкомпонентные (съёмником);
   - болт с несъёмным стопорным кольцом по центру → самосъёмный болт.

3. СНЯТЬ СТАРЫЕ: ВЫЗОВ соответствующей вспомогательной функции (снятие).

4. ОСМОТР: подшипники каретки (люфт, хруст) — при износе → ВЫЗОВ Заменить каретку()
   [BB-01 / BB-02].

5. ПОСТАВИТЬ НОВЫЕ: ВЫЗОВ той же вспомогательной функции (установка).

6. Проверить зазор шатун–перо и чейнлайн.

7. ЕСЛИ изменился BCD / размер звёзд → ВЫЗОВ Настроить передний переключатель()
   [DRV-02].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - нет люфта и хруста; шатуны параллельны, крутятся свободно;
  - чейнлайн в норме; моменты соблюдены.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель и длина шатунов, звёзды, тип крепления, моменты, предзатяг.
```

### ФУНКЦИЯ Заменить или обслужить педали(действие: замена | обслуживание)

```
Код операции : BB-05
Вход         : велосипед на стойке
Инструмент   : педальный ключ / hex 6–8 мм, метчик резьбы педали (TAP-6 для
               9/16″×20; TAP-3 для 1/2″×20), штатный ключ разборки оси педали,
               смазка, динамометрический ключ
Расходники   : педали / ремкомплект оси
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить L / R по маркировке на оси / лысках.
   1.2. Тип резьбы: 9/16″×20 (взрослые) / 1/2″×20 (one-piece).
   1.3. Тип педалей: платформа / SPD / SPD-SL / Look / Speedplay.

2. СНЯТЬ:
   2.1. Правая педаль — против часовой; левая — по часовой.
   2.2. ЕСЛИ прикипела → проникающая смазка, рычаг, аккуратный нагрев.

3. РЕЗЬБА ШАТУНА:
   3.1. Осмотреть; ЕСЛИ повреждена / забита → прогнать метчиком (TAP-6 / TAP-3).
   3.2. При срыве → резьбовставка или замена шатуна.

4. ЕСЛИ действие = обслуживание (SPD-подобные):
   4.1. Снять контргайку / крышку оси штатным ключом, извлечь картридж оси.
   4.2. Промыть, осмотреть конусы / шарики / пыльники, заменить изношенное,
        набить смазкой.
   4.3. Собрать, отрегулировать конус (свободно без люфта), законтрить.

5. УСТАНОВИТЬ:
   5.1. Обильно смазать резьбу.
   5.2. Правую — по часовой, левую — против часовой; наживить от руки строго ровно.
   5.3. Затянуть моментом по спецификации (обычно ~35 Н·м).

6. ЕСЛИ контактные педали → выставить усилие пружины, проверить вход и выход.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - педаль затянута моментом, крутится свободно без люфта;
  - клипса щёлкает и держит; L / R не перепутаны.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель педалей; прогон метчиком да / нет; замена или обслуживание; усилие клипс.
```

### ФУНКЦИЯ Торцевание посадочных мест каретки()

```
Код операции : BB-06
Вход         : велосипед на стойке, система и каретка сняты
Инструмент   : набор нарезки и торцевания (2 метчика + фреза + 2 ручки со
               штангой-направляющей), для press-fit — фреза расточки / торцов,
               смазка для инструмента
```

```
Функция покрывает и торцевание (выравнивание торцов стакана), и прогонку резьбы.

1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Показания: новая рама; наплывы / краска мешают наживить каретку; торцы
        стакана непараллельны (каретка с перекосом, скрип, быстрый износ);
        резьба «закусывает».
   1.2. Тип стакана: резьбовой (прогонка резьбы + торцевание) или press-fit
        (торцевание / расточка по стандарту).

2. РЕЗЬБОВОЙ СТАКАН — ПРОГОНКА РЕЗЬБЫ:
   2.1. Собрать метчики в ручки, смазать.
   2.2. Заводить с ОБЕИХ сторон одновременно, штанга держит соосность;
        правый метчик — левая резьба, левый — правая.
   2.3. Резать малыми ходами (вперёд — чуть назад), убирая стружку; не форсировать.
   2.4. Прогнать до чистой резьбы по всей длине.

3. ТОРЦЕВАНИЕ:
   3.1. Установить фрезу с направляющей, смазать.
   3.2. Снимать материал равномерно с обоих торцов, ПОКА не получится чистая
        параллельная поверхность по всему кольцу (сплошной след фрезы).
   3.3. Снимать минимум необходимого.

4. PRESS-FIT СТАКАН: торцевание / расточка соответствующим инструментом по стандарту.

5. ОЧИСТКА: тщательно убрать всю стружку и смазку.
```
