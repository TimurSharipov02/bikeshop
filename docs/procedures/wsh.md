### ФУНКЦИЯ Помыть велосипед()

```
Код операции : WSH-01
Вход         : велосипед на стойке
Инструмент   : набор щёток, машинка для чистки цепи, обезжириватель, смазка цепи,
               фиктивная втулка (dummy hub), тряпки / губки, 2 ведра, средство для
               мытья посуды, шланг (низкое давление, широкий распыл)
```

```
1. ВХОДНОЙ КОНТРОЛЬ: снять электронику / сумки / что боится воды; учесть, что
   после мойки нужна смазка трансмиссии.

2. ТБ ПО ВОДЕ: только низкое давление, широкий распыл; НЕ направлять струю в
   подшипники (каретка, втулки, рулевая, ролики). Сжатым воздухом в подшипники
   не дуть.

3. ТРАНСМИССИЯ — ПЕРВОЙ (самая грязная):
   3.1. Снять заднее колесо, поставить фиктивную втулку (или оставить колесо,
        наклонив кассетой вниз, чтобы растворитель не тёк в подшипник).
   3.2. Машинкой с обезжиривателем прогнать цепь; вылить, залить мыльную воду,
        прогнать ещё раз.
   3.3. Ролики переключателя, звёзды, кассету — щёткой с обезжиривателем
        (колесо кассетой к земле).
   3.4. Смыть.

4. РАМА И КОМПОНЕНТЫ: мыльной губкой и щётками сверху вниз; отдельная щётка для
   грязных мест, мягкая — для рамы.

5. КОЛЁСА: обода, спицы, покрышки; роторы — только чистой водой или спец.
   очистителем, без масла.

6. Смыть полностью, стряхнуть воду.

7. СУШКА: на воздухе или тряпкой; не дуть в подшипники.

8. СМАЗКА: цепь — по капле на звено, дать впитаться, излишек снять тряпкой;
   ролики, открытые участки тросов, точки вращения переключателей.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чисто; трансмиссия сухая и смазана;
  - ротор без масла (тест торможения); в узлах воды нет.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - выполнена мойка; тип смазки цепи.
```

ИСТОЧНИК: Park Tool, How to Wash a Bicycle — https://www.parktool.com/en-us/blog/repair-help/bike-washing-and-cleaning

### ФУНКЦИЯ Помыть велосипед с консервацией трансмиссии()

```
Код операции : WSH-02
Вход         : велосипед на стойке
Инструмент   : инструмент WSH-01 + ультразвуковая ванна ИЛИ ёмкость для
               парафинирования с нагревом и термометром, парафин / восковая
               смазка, съёмник замка цепи, растворитель для полного обезжиривания
```

```
1. ВЫЗОВ Помыть велосипед() [WSH-01] — рама и компоненты.

2. СНЯТЬ ЦЕПЬ (расстегнуть замок).

3. ПОЛНОЕ ОБЕЗЖИРИВАНИЕ ЦЕПИ:
   3.1. Ультразвук → 2–3 цикла в обезжиривателе, промывка, полная сушка
        (тепло / продувка).
   ИЛИ
   3.2. Ручное → несколько бань в растворителе со встряхиванием, финальная в
        чистом растворителе, сушка.

4. ЕСЛИ парафинирование:
   4.1. Растопить парафин / воск (температура по продукту, обычно ~70–90 °C).
   4.2. Опустить обезжиренную сухую цепь на 15–20 мин, поводить, чтобы парафин
        зашёл в ролики.
   4.3. Достать, дать стечь, остыть; «переломить» каждое звено, чтобы цепь
        стала гибкой.

5. ЕСЛИ капельная восковая смазка → обильно нанести на чистую сухую цепь по
   звеньям, прогнать, дать высохнуть, снять излишек.

6. КАССЕТА И ЗВЁЗДЫ: снять кассету [DRV-04], промыть отдельно, просушить;
   звёзды системы обезжирить.

7. СОБРАТЬ: цепь на место, замок дожать под нагрузкой;
   ВЫЗОВ Диагностика износа трансмиссии() [DRV-09] заодно.

8. Короткий прогон под нагрузкой.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - трансмиссия чистая, тихая, без липкого налёта;
  - цепь гибкая; переключение чистое.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - метод (ультразвук / парафин / воск); износ цепи (%).
```

ИСТОЧНИК: Park Tool, How to Wash a Bicycle — https://www.parktool.com/en-us/blog/repair-help/bike-washing-and-cleaning ; мануал восковой смазки / парафина.

### ФУНКЦИЯ Законсервировать велосипед на хранение()

```
Код операции : WSH-03
Вход         : велосипед на стойке
Инструмент   : щётки, смазка цепи, антикоррозийный спрей (тефлон / силикон),
               неплотный чехол / подставка
```

```
1. ВЫЗОВ Помыть велосипед() [WSH-01].

2. ОСМОТР перед хранением: износ трансмиссии [DRV-09], колодки, покрышки, тросы.
   Зафиксировать в наряде, что потребует внимания весной.

3. ТРАНСМИССИЯ: обильно смазать цепь (для хранения гуще обычного), излишек не
   вытирать; звёзды и ролики тонким слоем.

4. ЗАЩИТА ОТ КОРРОЗИИ: лёгкий защитный спрей на открытые болты, пружины тормозов
   и переключателей, оси эксцентриков. НЕ на роторы и колодки.

5. ДАВЛЕНИЕ И КАМЕРЫ: подкачать покрышки до рабочего давления; на длительное
   хранение — подвесить велосипед или переворачивать раз в месяц.

6. ГИДРАВЛИКА: рычаги долго зажатыми не фиксировать; проставку в суппорт при
   снятых колёсах.

7. ЭЛЕКТРОНИКА: АКБ снять, зарядить до ~60 %, хранить отдельно в тепле.

8. ХРАНЕНИЕ: сухое помещение без перепадов температуры; неплотный чехол
   (не полиэтилен вплотную — конденсат).
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чисто, смазано; покрышки держат давление;
  - электроника снята и заряжена; список весенних работ записан.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - дата консервации; что осмотрено; список работ на весну.
```

ИСТОЧНИК: общая практика; Park Tool, How to Wash a Bicycle — https://www.parktool.com/en-us/blog/repair-help/bike-washing-and-cleaning
