Функции группы STR. Нотация — в `README.md`.

### ФУНКЦИЯ Отрегулировать рулевую()

```
Код операции : STR-01
Вход         : велосипед на стойке
Инструмент   : шестигранники, ограничитель момента / динамометрический ключ
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Люфт: зажать передний тормоз, покачать велосипед вперёд-назад, рука на
        стыке рулевой — стук.
   1.2. Закусывание: поднять перед, повернуть руль — «ступенька» или
        самоцентрирование в положении «прямо» = дорожка нижней чашки выбита шариками (вмятины).
        Регулировкой не лечится → СОГЛАСОВАТЬ замену рулевой.
   1.3. Проверить: шток на ~3 мм ниже верха выноса (крышке есть куда давить).
        При необходимости добавить / убрать проставку.

2. РЕГУЛИРОВКА:
   2.1. Ослабить болты стяжки выноса на штоке; убедиться, что вынос свободно
        поворачивается.
   2.2. Болт крышки — по 1/8 оборота по часовой, наращивая преднатяг.
   2.3. После каждого шага: подтянуть болты выноса, проверить люфт и вращение.
   2.4. Цель — самое свободное положение без стука.

3. ФИКСАЦИЯ: выставить вынос перпендикулярно колесу, затянуть болты стяжки
   моментом по спецификации (обычно 5–6 Н·м; карбоновый шток — строго по мануалу).
```

```
ПРОВЕРКА КАЧЕСТВА:
  - люфта нет (тест с тормозом); руль вращается плавно, без ступеньки;
  - болты выноса затянуты моментом.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - изменение числа проставок; момент болтов выноса.
```

### ФУНКЦИЯ Перебрать рулевую()

```
Код операции : STR-02
Вход         : велосипед на стойке
Инструмент   : шестигранники, съёмник чашек, съёмник нижнего кольца, пресс чашек,
               установщик нижнего кольца, смазка, ветошь
Расходники   : подшипники / картриджи / чашки / нижнее кольцо по износу
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить тип: внешние чашки (EC), полуинтегрированная / zero-stack (ZS),
        интегрированная (IS — картриджи ложатся в раму без чашек).
   1.2. Определить подшипники: насыпные в обойме, промкартриджи, угловой контакт.

2. РАЗБОРКА:
   2.1. Снять вынос, проставки, вилку.
   2.2. IS → вынуть картриджи, осмотреть; «переборка» часто = замена картриджей
        и чистка посадочных мест рамы.
   2.3. EC / ZS → осмотр беговых дорожек; при вмятинах и раковинах от шариков заменить чашки / картриджи.

3. ЕСЛИ меняются внешние чашки:
   3.1. Выбить старые съёмником чашек (лепестки, удар молотком).
   3.2. Проверить натяг: наружный диаметр чашки на 0.1–0.25 мм больше внутреннего
        диаметра трубы.
   3.3. Запрессовать прессом ровно, с направляющими.
        ПРОВЕРИТЬ: чашка полностью прилегает к торцу трубы по всему кругу.
   3.4. ЕСЛИ торцы неровные / краска мешает → ВЫЗОВ Запрессовать чашки рулевой()
        [STR-03] (там фрезеровка).

4. НИЖНЕЕ КОЛЬЦО (crown race):
   4.1. Снять старое съёмником или аккуратной выколоткой.
   4.2. Напрессовать новое установщиком до упора; при необходимости — разрезное.

5. СБОРКА:
   5.1. Смазать дорожки и картриджи; насыпные в обойме — открытой стороной к
        конусной дорожке.
   5.2. Собрать: вилка → нижний / верхний подшипник → пыльник → проставки →
        вынос → крышка.
   5.3. ВЫЗОВ Отрегулировать рулевую() [STR-01].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чашки сидят без зазора; вращение плавное, люфта нет; вилка не выпадает.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - тип рулевой; заменённые части; выполнялась ли фрезеровка.
```

### ФУНКЦИЯ Запрессовать чашки рулевой()

```
Код операции : STR-03
Вход         : рама / велосипед на стойке
Инструмент   : пресс чашек с адаптерами и направляющими, фреза посадочных мест
               головной трубы, штангенциркуль, монтажная паста / смазка
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Только для рулевых с внешними чашками (EC, частично ZS). Интегрированная
        (IS) — чашки не запрессовываются.
   1.2. Совместимость: стандарт головной трубы (EC34 / EC44, ZS44 / ZS56 и т.п.),
        диаметр штока (1‑1/8, тэйпер 1.5).
   1.3. Замер: наружный диаметр чашки на 0.1–0.25 мм больше внутреннего диаметра
        трубы. Меньше → запрессовка ненадёжна, СОГЛАСОВАТЬ.

2. ПОДГОТОВКА ТРУБЫ:
   2.1. Осмотреть торцы и посадочные пояски; удалить краску и заусенцы.
   2.2. ЕСЛИ торцы не параллельны / посадка не круглая → фрезеровка и торцевание
        посадочных мест головной трубы.

3. ЗАПРЕССОВКА:
   3.1. Тонкий слой монтажной пасты / смазки на пояски.
   3.2. Собрать пресс с адаптерами точно по размеру чашек, с направляющими
        (антиперекос).
   3.3. Прессовать равномерно, обе чашки к центру.
   3.4. ПРОВЕРИТЬ: каждая чашка полностью прилегает к торцу трубы по всему кругу;
        щуп 0.05 мм не проходит.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - чашки без зазора и перекоса;
  - после сборки рулевой (STR-02) вращение плавное.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - стандарт рулевой; выполнялась ли фрезеровка; модель чашек.
```

### ФУНКЦИЯ Заменить руль или вынос(внешняя проводка)

```
Код операции : STR-04
Вход         : велосипед на стойке
Инструмент   : шестигранники / Torx, динамометрический ключ, монтажная паста (карбон)
Расходники   : обмотка / грипсы при необходимости
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Совпадение диаметров: зажим выноса ↔ центр руля (25.4 / 31.8 / 35 мм);
        шток ↔ хомут выноса.
   1.2. Карбон-руль или карбон-шток → монтажная паста, строго моменты, не превышать.

2. ДЕМОНТАЖ:
   2.1. Снять обмотку / грипсы, аксессуары.
   2.2. Открутить крышку зажима руля, снять руль; при замене выноса — ослабить
        болты стяжки на штоке, снять.

3. МОНТАЖ ВЫНОСА:
   3.1. Надеть на шток с проставками, выставить угол.
   3.2. Болт крышки рулевой — преднатяг (STR-01), затем болты стяжки выноса
        моментом (обычно 5–6 Н·м).

4. МОНТАЖ РУЛЯ:
   4.1. Паста на зону зажима (карбон).
   4.2. Выставить угол и центровку по меткам; болты крышки зажима крест-накрест
        равными шагами, зазоры сверху и снизу одинаковые, момент по спецификации
        (обычно 5–6 Н·м).

5. Переставить манетки / ручки и аксессуары; проверить свободный ход тросов при
   повороте руля.

6. ВЫЗОВ Обмотать руль() [STR-07] (шоссе / гревел) или поставить грипсы.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - моменты соблюдены, зазоры равные, руль не проворачивается под усилием;
  - тросы не натянуты в крайних поворотах руля.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модели руля / выноса; длина выноса и угол; моменты; применена ли паста.
```

### ФУНКЦИЯ Заменить кокпит с интегрированной проводкой()

```
Код операции : STR-05
Вход         : велосипед на стойке
Инструмент   : шестигранники / Torx, набор для внутренней проводки, при
               необходимости набор для прокачки тормозов и обрезки гидролинии
Расходники   : кокпит; при вскрытии — жидкость, наконечники, тросы / рубашки
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Схема проводки: через вынос → верхнюю крышку рулевой → в раму;
        совместимость нового кокпита с рулевой и рамой.
   1.2. Оценить, что придётся вскрывать: гидролинии (→ прокачка), тросы, провода Di2.
   1.3. Сфотографировать исходную прокладку и вылеты.

2. ДЕМОНТАЖ:
   2.1. Снять обмотку; вывести / отсоединить линии и тросы.
   2.2. Разобрать рулевую сверху (крышка, компрессионное кольцо, верхний
        подшипник), высвободить каналы.
   2.3. Снять старый кокпит; при внутренней проводке протянуть направляющие лески.

3. МОНТАЖ:
   3.1. Поставить новый вынос / руль на пасту, не затягивать до укладки линий.
   3.2. Провести линии / тросы / провода по каналам кокпита и через крышку
        рулевой в раму по направляющим.
   3.3. Собрать рулевую, ВЫЗОВ Отрегулировать рулевую() [STR-01].
   3.4. Затянуть кокпит моментами (STR-04).

4. ВОССТАНОВИТЬ СИСТЕМЫ:
   4.1. ЕСЛИ гидролинии резались / отсоединялись → ВЫЗОВ Прокачать гидравлические
        тормоза() [BRK-04] (и Заменить гидролинию() [BRK-05] при обрезке).
   4.2. ЕСЛИ тросы менялись → ВЫЗОВ настроек [DRV-01 / DRV-02 / BRK-01].
   4.3. Di2 — проверить соединения.

5. ВЫЗОВ Обмотать руль() [STR-07].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - руль поворачивается на полный угол без натяга линий и закусывания;
  - рулевая без люфта; тормоза и переключение работают; нет трения и щелчков.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель кокпита; что вскрывалось; прокачка / настройки — отдельными операциями;
  - моменты.
```

### ФУНКЦИЯ Проложить тросы и линии через раму(внутренняя проводка)

```
Код операции : STR-06
Вход         : велосипед на стойке
Инструмент   : набор для внутренней проводки (магнитный проводник, лески-
               направляющие), кусачки, при необходимости набор для прокачки
```

```
1. ВХОДНОЙ КОНТРОЛЬ: схема каналов рамы (направляющие трубки, люверсы, порты);
   что прокладываем (трос + рубашка, гидролиния, провод Di2).

2. СОХРАНИТЬ КАНАЛ:
   2.1. ЕСЛИ в раме сквозные направляющие трубки → протолкнуть новое сквозь них.
   2.2. ИНАЧЕ → до вытаскивания старого привязать направляющую леску или
        использовать магнитный проводник.

3. ПРОКЛАДКА:
   3.1. Завести проводник от входного порта к выходному (магнит помогает у
        каретки и рулевой).
   3.2. Присоединить трос / линию / провод, протянуть, снять проводник.
   3.3. Поставить люверсы / заглушки портов; зафиксировать от дребезга по мануалу
        рамы (поролон, стяжки внутри).

4. ЗАВЕРШЕНИЕ: обрезать рубашки по длине (плавные дуги, поворот руля свободен),
   наконечники.

5. ВЫЗОВ соответствующей настройки или прокачки.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - линии в раме не дребезжат (потрясти велосипед); поворот руля свободен;
  - система работает.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - что проложено; тип портов / люверсов; чем сделан антидребезг.
```

### ФУНКЦИЯ Обмотать руль()

```
Код операции : STR-07
Вход         : манетки установлены и затянуты; тросы / линии уложены и прихвачены
               к рулю тонкой лентой
Инструмент   : ножницы
Расходники   : комплект ленты руля с заглушками, финишная лента / изолента
```

```
1. ПОДГОТОВКА:
   1.1. Резиновые манжеты манеток отвернуть вперёд.
   1.2. Приложить короткий кусок ленты за хомутом манетки сверху (закрыть разрыв),
        если есть в комплекте.

2. ОБМОТКА:
   2.1. Начать с торца руля, оставив ~половину ширины ленты за краем (заправится
        заглушкой).
   2.2. Мотать с равным натягом и перекрытием 1/3–1/2, в направлении, при котором
        хват руки не разматывает ленту (обычно снизу вверх с внешней стороны).
   2.3. У манетки — «восьмёрка» вокруг хомута, зона закрыта без просветов.
   2.4. Дойти до подъёма руля минимум на 2 оборота выше конечной точки.

3. ФИНИШ:
   3.1. Отрезать ленту по диагонали для ровного схода.
   3.2. Зафиксировать финишной лентой в 2–3 оборота.
   3.3. Заправить хвостики в торцы, вставить заглушки.
   3.4. Вернуть манжеты манеток на место.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - намотка равномерная, без просветов у манеток; заглушки держатся;
  - левая и правая стороны симметричны.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель ленты.
```

### ФУНКЦИЯ Установить велокомпьютер и датчики()

```
Код операции : STR-08
СТАТУС       : у Park Tool отдельной статьи нет; порядок общий.
Вход         : велосипед на стойке
Инструмент   : шестигранники, обезжириватель
Расходники   : кронштейн, стяжки / резинки из комплекта, батарейки датчиков
```

```
1. ВХОДНОЙ КОНТРОЛЬ: тип крепления (руль / вынос / аутфронт); протокол датчиков
   (ANT+ / Bluetooth); что ставим — скорость, каденс, мощность, пульс.

2. КОМПЬЮТЕР: поставить кронштейн (вынос или аутфронт под руль), затянуть без
   перетяга (карбон — момент), проверить надёжность и угол обзора.

3. ДАТЧИКИ:
   3.1. Скорость — на втулку (безмагнитный) либо геркон на пере + магнит на спице
        (зазор ~2–3 мм).
   3.2. Каденс — на шатун (безмагнитный) либо датчик на пере + магнит на шатуне.
   3.3. Мощность — калибровка (обнуление) по инструкции.
   3.4. Пульс — нагрудный ремень / оптический.

4. СПАРИВАНИЕ: добавить каждый датчик в меню компьютера по ID; задать окружность
   колеса (для скорости) или выбрать размер покрышки.

5. ПРОВЕРКА на тест-прокрутке или поездке: все датчики дают данные; крепления не
   болтаются; ничего не задевает.
```

```
ФИКСИРОВАТЬ В НАРЯДЕ:
  - модель компьютера и датчиков; окружность колеса; выполнена ли калибровка мощности.
```

ИСТОЧНИК: Park Tool, Di2 Shimano Electronic System Installation (смежное) — https://www.parktool.com/en-us/blog/repair-help/di2-shimano-electronic-intelligent-system-installation
