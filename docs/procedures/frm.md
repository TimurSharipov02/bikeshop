# Рама (FRM)

Функции группы FRM. Нотация — в `README.md`.

> **Материал рамы решает всё.** Механическая обработка (нарезка, торцевание,
> правка) допустима по МЕТАЛЛУ и по металлическим вставкам. Карбон, титан,
> клееные соединения — не обрабатывать и не править; при сомнении — к
> производителю.

---

### ФУНКЦИЯ Подготовить новую раму()

```
Код операции : FRM-01
Вход         : рама на стойке, до сборки
Инструмент   : набор торцевания каретки, фреза головной трубы, калибр петуха,
               метчики рам (M5, M3, M10), калибры дропаутов, прибор соосности рамы
```

```
1. ВХОДНОЙ КОНТРОЛЬ: материал рамы; список посадочных мест (каретка, рулевая,
   петух, крепление калипера, дропауты, бонки, подседельный хомут).
   ЗАМЕТКА: по карбону механическую обработку НЕ вести — только по металлическим
   вставкам и по инструкции производителя.

2. КАРЕТКА: ВЫЗОВ Торцевание посадочных мест каретки() [BB-06].

3. РУЛЕВАЯ: осмотр посадочных мест.
   ЕСЛИ внешние чашки и торцы головной трубы неровные (металл) → ВЫЗОВ
   Запрессовать чашки рулевой() [STR-03] с торцеванием.

4. ПЕТУХ: ВЫЗОВ Отъюстировать петух() [DRV-07].

5. ДРОПАУТЫ: проверить параллельность калибрами (только металл; карбон / титан /
   клееные — не править, к производителю). При отклонении → FRM-02, шаг 6.

6. РЕЗЬБЫ НАВЕСНОГО: прогнать метчиками резьбу бонок (M5×0.8), крепления калипера
   и поста (M5), винтов юстировки дропаута (M3×0.5).
   При повреждении → ВЫЗОВ Восстановить резьбу() [FRM-05].

7. СООСНОСТЬ: прибором проверить, что головная труба, подседельная труба и задние
   дропауты в одной плоскости.
   Отклонение → к производителю / рамостроителю (правка возможна у стали, у
   карбона / алюминия / титана — обычно нет).

8. ЕСЛИ клиент хочет защиту → ВЫЗОВ Установить защитные плёнки() [FRM-04].
```

```
ПРОВЕРКА КАЧЕСТВА:
  - все резьбы наживляются от руки;
  - каретка и рулевая без перекоса; петух в допуске;
  - дропауты параллельны; соосность в норме.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - материал рамы; что обрабатывалось; отклонения соосности.
```

### ФУНКЦИЯ Проверить раму после аварии()

```
Код операции : DIA-03 / FRM-02
Вход         : велосипед на стойке
Инструмент   : фонарь, лупа, прибор соосности рамы, калибры дропаутов, калибр петуха
```

```
1. ВХОДНОЙ КОНТРОЛЬ: характер удара (лобовой, боковой, падение на бок, наезд);
   жалобы клиента; материал рамы.

2. ВИЗУАЛЬНЫЙ ОСМОТР по зонам риска:
   - низ и верх головной трубы, зона за головной трубой на верхней и нижней
     трубе (лобовой удар);
   - перья у каретки, дропауты, петух;
   - подседельная труба у выхода штыря, стык верхней и подседельной труб;
   - сварные швы и зоны стыков.
   Искать: трещины, вздутие лака, «морщины» карбона, смятие, матовые пятна
   расслоения, потёкшую смолу.

3. ПРОВЕРКА НАГРУЗКОЙ: держась за раму, аккуратно нагрузить в плоскостях — искать
   неожиданную податливость, щелчки, хруст, скрип из одной точки.

4. ГЕОМЕТРИЯ:
   4.1. Прибором проверить соосность (головная — подседельная — дропауты).
   4.2. Калибрами проверить параллельность дропаутов (металл).
   4.3. Калибром проверить петух.

5. ВЫВОД:
   - Металл, лёгкая деформация дропаута / петуха, трещин нет → правка допустима
     (шаг 6 / DRV-07).
   - Любая трещина, расслоение карбона, деформация труб, нарушенная соосность →
     раму НЕ эксплуатировать; СОГЛАСОВАТЬ С КЛИЕНТОМ: экспертиза производителя
     или замена.

6. ПРАВКА ДРОПАУТОВ (только металл, трещин нет):
   6.1. Калибры в дропауты, подтянуть.
   6.2. Втулки калибров отрегулировать до малого зазора, отцентровать.
   6.3. Гнуть малыми приращениями (рычаг калибра и рука, руки в разные стороны),
        перепроверять.
   6.4. Цель: смещение цилиндров калибров ≤ 0.5 мм.
   ЗАМЕТКА: НЕ править — толстые кованые дропауты, титан, карбон / клееные,
   большинство вилок. К производителю.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - трещин и расслоений нет; соосность и дропауты в допуске;
  - ИЛИ выдан вердикт «к производителю / замена».
ФИКСИРОВАТЬ В НАРЯДЕ:
  - характер удара; найденные дефекты; замеры; вердикт.
  - При отправке к производителю — акт и фото.
```

### ФУНКЦИЯ Восстановить направляющие внутренней проводки()

```
Код операции : FRM-03
Вход         : велосипед на стойке
Инструмент   : набор для внутренней проводки (магнитный проводник, лески),
               кусачки, стяжки / поролон / термоусадка
Расходники   : люверсы, заглушки портов, направляющие трубки под модель рамы
```

```
1. ВХОДНОЙ КОНТРОЛЬ: что повреждено / утрачено — резиновые люверсы портов,
   внутренние направляющие трубки, клипсы фиксации, заглушки пустых портов.
   Подобрать оригинальные детали по модели рамы.

2. ЕСЛИ утрачена сквозная направляющая трубка:
   2.1. Протянуть новую от порта к порту магнитным проводником / леской.
   2.2. Обрезать с запасом у портов, зафиксировать люверсами.

3. ЗАМЕНА ЛЮВЕРСОВ / ЗАГЛУШЕК: снять старые, поставить новые под нужный набор
   линий (трос, гидролиния, провод, пусто).

4. АНТИДРЕБЕЗГ: если линии стучат в раме — протянуть термоусадку / поролон по
   линии или закрепить по мануалу рамы.

5. Собрать линии; ВЫЗОВ соответствующих настроек / прокачки, если снимались.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - линии проходят свободно, не дребезжат (потрясти велосипед);
  - порты закрыты; неиспользуемые заглушены.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - какие детали заменены; чем сделан антидребезг.
```

ИСТОЧНИК: специализированной статьи Park Tool нет; смежное — Shift Cable
Replacement: Drop Bars — https://www.parktool.com/en-us/blog/repair-help/shift-cable-replacement-drop-bars ; мануал рамы.

### ФУНКЦИЯ Установить защитные плёнки()

```
Код операции : FRM-04
СТАТУС       : у Park Tool статьи нет; порядок по общей практике оклейки.
Вход         : велосипед на стойке, помещение без пыли
Инструмент   : ножницы / скальпель (резать только на столе, не на раме),
               фен / тепловая пушка, ракель, мыльная вода, изопропил, безворсовая ветошь
Расходники   : набор плёнок под модель или листовая уретановая плёнка
```

```
1. ВХОДНОЙ КОНТРОЛЬ: зоны под защиту — низ нижней трубы (камни), перо под цепью,
   зона у рулевой под тросами, верхняя труба под тросами, дропауты. Матовая
   или глянцевая.

2. ПОДГОТОВКА: вымыть раму, обезжирить изопропилом, высушить; рама комнатной
   температуры.

3. РАСКРОЙ: приложить готовые детали или вырезать по лекалу НА СТОЛЕ. Углы скруглить.

4. МОНТАЖ (мокрый способ):
   4.1. Смочить поверхность рамы и клеевую сторону плёнки мыльной водой.
   4.2. Приложить, позиционировать; ракелем от центра к краям выгонять воду и пузыри.
   4.3. Сложные изгибы — прогреть феном и растянуть; остудить в натянутом положении.
   4.4. Края прокатать и прогреть для прилипания.

5. СУШКА: сутки не мочить и не эксплуатировать; окончательная адгезия — несколько
   дней.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - пузырей и складок нет; края приклеены;
  - плёнка не заходит на зажимные и подвижные зоны (хомут подседела, посадочные).
ФИКСИРОВАТЬ В НАРЯДЕ:
  - какие зоны оклеены; тип плёнки.
```

### ФУНКЦИЯ Восстановить резьбу()

```
Код операции : FRM-05
Вход         : велосипед на стойке
Инструмент   : метчики рам — M5×0.8 (бонки, калипер, эксцентрики), M3×0.5 (винты
               юстировки дропаута), M10×1.0 (петух — частый), M6; набор
               резьбовставок (Helicoil) M5; смазка для метчика
```

```
1. ВХОДНОЙ КОНТРОЛЬ:
   1.1. Определить место и резьбу: бонки флягодержателя M5×0.8; крепление калипера
        / поста M5; винты юстировки дропаута M3×0.5; петух — по модели (часто
        M10×1.0); подседельный хомут.
   1.2. Оценить: резьба цела, но забита / закисла (нужна прогонка) ИЛИ сорвана
        (нужна резьбовставка или иное).

2. ПРОГОНКА (резьба цела):
   2.1. Метчик нужного шага, смазать, заводить строго по оси малыми ходами
        вперёд — чуть назад, убирая стружку.
   2.2. Продуть; проверить винтом — заходит от руки.

3. СОРВАННАЯ РЕЗЬБА:
   3.1. Сталь / алюминий, материала достаточно → рассверлить под резьбовставку,
        нарезать, установить Helicoil (обычно M5).
   3.2. Карбоновая вставка бонки → коил обычно НЕ ставится (мало материала).
        Вариант: винт M4 изнутри рамы как шпилька + гайка снаружи; либо
        специализированный ремонт у производителя.
   3.3. Стальная рама с вваренной бонкой → замена / переварка бонки
        (сварка — сторонний исполнитель).
   3.4. Срыв резьбы под петух → замена петуха; при срыве в сменном дропауте —
        замена дропаута.

4. ЗАЩИТА: капля антисиза на восстановленную резьбу при сборке.
```

```
ПРОВЕРКА КАЧЕСТВА:
  - винт заходит от руки на полную глубину и держит момент;
  - флягодержатель затягивается без прокрутки.
ФИКСИРОВАТЬ В НАРЯДЕ:
  - место; резьба; метод (прогонка / Helicoil / шпилька / замена детали).
```
