# Приёмка и диагностика

Функции группы DIA. Нотация — в `README.md`.
Рабочий источник — `catalog/intake.proc`.

Диагностика построена как пары **действие → ПРОВЕРКА «— норма?»**. Ответ «нет»
раскрывает список типовых неисправностей своей группы (`catalog/faults.json`):
мастер отмечает нужные (можно несколько) и пишет комментарий — они сразу падают
в список работ наряда.

---

### ФУНКЦИЯ Приёмка — диагностика велосипеда()

```
Код операции : DIA-01
Параметры    : вилка (жёсткая | амортизационная); тормоз (диск | обод)
Вход         : запрос клиента зафиксирован; велосипед у мастера в руках
Инструмент   : шестигранники, динамометрический ключ, фонарь, чек-лист
```

**Глава 1. Колёса (велосипед в руках)** — для заднего, затем переднего колеса:

```
1.1. Взять колесо за обод и подвигать вбок (перпендикулярно велосипеду);
     проверить, плотно ли сидит в дропаутах.
     ПРОВЕРКА [HUB]: втулка без люфта; колесо сидит плотно — норма?
1.2. Приподнять велосипед так, чтобы это колесо повисло; раскрутить и смотреть
     биение обода вбок и по радиусу, зонт, целость спиц.
     ПРОВЕРКА [RIM]: обод без восьмёрки и яйца, зонт в норме, спицы целы — норма?
1.3. Осмотреть покрышку; прикинуть давление рукой.
     ПРОВЕРКА [TIRE]: протектор не стёрт, без порезов и грыж, не спущено — норма?
1.4. Остановить колесо его тормозом; зажать с усилием и попробовать провернуть;
     посмотреть, не бьёт ли ротор и не задевают ли колодки.
     ПРОВЕРКА [BRK]: ход ручки и схватывание в норме, тормозит уверенно и держит;
     ротор не бьёт, колодки не задевают — норма?
```

**Глава 2. Кареточный узел**

```
Покачать шатуны вбок (перпендикулярно раме); прокрутить педали назад вхолостую.
ПРОВЕРКА [BB]: каретка без люфта; вращение без хруста и заеданий — норма?
```

**Глава 3. Рулевая колонка**

```
Зажать передний тормоз, покачать велосипед вперёд-назад (рука на верхней чашке);
приподнять перед, повернуть руль от упора до упора.
ПРОВЕРКА [STR]: рулевая без люфта; вращается плавно, без «ступеньки» — норма?
```

**Глава 4. Вилка** (только амортизационная)

```
Зажать передний тормоз, покачать велосипед; продавить вилку несколько раз.
ПРОВЕРКА [SUS]: вилка без люфта; ход плавный; нет подтёков масла — норма?
```

**Глава 5. Рама**

```
Осмотреть раму в целом и в районе предстоящих работ (глубокая дефектовка не проводится).
ПРОВЕРКА [FRM]: трещин, вздутий лака и деформаций не видно; при покачивании
колёс мягкость не ощущалась — норма?
ЕСЛИ по раме есть сомнения → ВЫЗОВ Проверить раму после аварии() [DIA-03 / FRM-02],
СОГЛАСОВАТЬ С КЛИЕНТОМ, СТОП до решения по раме.
```

**Глава 6. На стойке — переключение**

```
Повесить велосипед на стойку, прокрутить педали, переключиться по всей кассете.
ЕСЛИ есть передний переключатель → проверить все комбинации, трение цепи о рамку.
ПРОВЕРКА [DRV]: переключение чёткое по всей кассете, без задержек, перескоков
и шума на прямой цепи — норма?
Проверить ровность петуха на глаз; замерить износ цепи измерителем; осмотреть
зубья кассеты и звёзд. ЕСЛИ группа электронная → проверить заряд АКБ и связь.
ПРОВЕРКА [DRV]: петух ровный; цепь, кассета, звёзды не изношены — норма?
```

**Глава 7. Результат** — собранные неисправности идут в список работ на
согласование с клиентом; по каждой отмечаются риски и нужные запчасти.

### ФУНКЦИЯ Повторная диагностика (после ремонта)()

```
Код операции : DIA-01R — обязательна перед выдачей
Вход         : все работы по наряду выполнены
```

```
1. ВЫЗОВ Приёмка — диагностика велосипеда() [DIA-01] — тот же прогон целиком.
2. Проверить моменты затяжки ответственных болтов: вынос, руль, подседельный
   штырь, хомут седла, болты суппортов и роторов, ось / эксцентрики, болты
   бачков и навесного.
3. ПРОВЕРКА: критерии приёмки всех выполненных операций (из их процедур).
4. Тест-райд; для велосипедов спортсменов — обязательно с переключением под усилием.
```
