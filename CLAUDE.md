# Инструкции для Claude в этом проекте

Проект: Veloterra (веломастерская) — `TimurSharipov02/bikeshop` на GitHub, ветка
`main`. Репозиторий подключён к Vercel через GitHub-интеграцию: любой пуш в
`main` автоматически собирает и выкладывает новую версию на
`bikeshop-chi.vercel.app`.

## Автопуш в main разрешён заранее

Пользователь не разработчик и не будет сам пользоваться терминалом или git.
Он явно попросил (2026-09-11), чтобы после того как изменения в этой папке
готовы и проверены, Claude сам делал `git add` / `git commit` / `git push` в
`main` — не дожидаясь отдельного разрешения на каждый пуш. Это и есть способ
«выложить новую версию»: раз Vercel подключён к GitHub, push в `main` = деплой.

Что это означает на практике:
- Не нужно спрашивать «запушить?» перед каждым отдельным пушем — это
  разрешено заранее, как и требуют общие правила безопасности (стандартное
  разрешение действует, если оно записано в durable-инструкциях вроде этого
  файла).
- Всё равно стоит по ходу коротко говорить, что именно запушено и что это
  означает для сайта (например: «обновил прайс-лист, через минуту-две
  изменения будут на сайте»), т.к. пользователь не будет сам читать git log.
- Разрешение не распространяется на force-push, изменение истории (reset
  --hard, amend опубликованных коммитов) или на другие ветки/репозитории —
  для этого по-прежнему нужно явное согласие в чате.
